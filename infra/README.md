# 历史服务开发配置

当前 Knora 桌面客户端已内置本机 API、Worker、SQLite 和模型执行器，不需要运行本目录中的 Docker 服务。

这里保留早期 API/Worker/PostgreSQL 和 Crawl4AI 配置作为开发参考。现有 Dockerfile 按早期目录布局复制模块，当前共享内核的模块布局已有变化；这些镜像未完成本轮适配和启动回归，不能作为经过验证的当前产品部署方式。Compose 配置语法检查通过不等于镜像运行或功能验收通过。

修改桌面产品请使用 [macOS 构建流程](../apps/macos/BUILD.md)，独立源码开发与测试见 [开发与验证](../docs/开发与验证.md)。服务化部署的目录适配、模型源、认证与网络边界应另行评估和验证。
