# 知径 · Knora

本地优先的个人知识库，面向 macOS。把笔记、网页和文件收集到自己的知识库，随时阅读、搜索，并用自己配置的 AI 服务分析和提问。

项目原创源码采用 [GPL-3.0-only](LICENSE)。第三方组件保留各自的版权和许可证，见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 主要功能

- **收集**：粘贴文字和链接、导入文件、拖放与浏览器采集；队列展示处理进度并支持失败重试。
- **整理与阅读**：知识库、项目、标签、图片原件、PDF 阅读、阅读位置恢复、回收站和本地备份。
- **搜索**：精确搜索默认可用；安装语义搜索扩展后，可按含义检索正文及已生成的摘要。
- **AI**：在客户端配置模型 API 地址、API Key 和模型名，进行文章分析、知识库更新和引用原文的问答。模型服务可能收费。
- **Agent**：按知识库授权只读访问，连接 Codex、Claude Code 或 Workbuddy；本机服务随客户端运行。
- **按需扩展**：语义搜索、文字识别、复杂文档解析单独安装，基础 App 保留云端 AI 调用代码。安装后需正常退出并重开客户端。

## 系统与安装

当前桌面客户端面向 **Apple Silicon、macOS 14.5+**。Intel、Windows、Linux 和移动端尚未完成产品发行验收。仓库中的移动端与 Docker 配置保留为历史开发参考，不属于当前桌面发行支持范围，也不是使用 macOS 客户端的前提。

首次公开发行尚在准备，暂不提供未经核验的下载链接。发布安装包后，将 DMG 中的 `Knora.app` 拖入 `Applications`，复制完成后从“应用程序”启动。当前本地测试包使用 ad-hoc 签名，未做 Apple 公证；这不等于已经通过跨设备安装验证。安装和发行步骤见 [打包说明](apps/macos/PACKAGING.md)。

客户端自带本机 Python、API、Worker 和 SQLite，**不用登录，不需要另启服务器、数据库、Docker 或 AI 网关**。设置中填写模型服务配置后即可使用云端 AI；未配置模型时仍可收集、阅读和精确搜索。

浏览器插件目前通过开发者模式加载，安装与本机桥接说明见 [浏览器插件](apps/extension/README.md)。飞书采集需要另行配置本机 CLI。

## 数据与隐私

资料默认保存在当前用户的 Mac。使用 AI 会向用户配置的模型服务发送相应内容；采集和扩展下载也会访问各自来源。模型密钥以当前用户私有文件保存，不随知识库备份导出。详见 [隐私与本地数据](docs/隐私与本地数据.md)。

内部应用标识、数据路径和 `knowledge-inbox://` 链接协议延续旧版本，以保持已有知识库和 Agent 连接兼容。产品旧名“知识收集箱”可能出现在历史设计与验收记录中。

```text
apps/macos/           SwiftUI 客户端、资源与打包脚本

services/api/         共享业务内核、本机 API、MCP、数据库和扩展管理
services/worker/      采集、解析、AI 分析、问答与索引任务
services/ai_gateway/  共享模型执行器；也保留外置开发入口
apps/mobile/          移动端开发原型
infra/                可选的服务端开发配置
docs/                 产品使用、开发验证与隐私说明
```

不应将开发虚拟环境、用户扩展、数据库、上传目录或本机配置复制进 App。修改后台代码后须连同运行包一起重建，单独编译 Swift 不会更新内置后台。
