# A0：一键 Agent 接入

日期：2026-10-03。默认流程：选择 Codex/Claude Code → 勾选授权领域 → 点击连接。连接名称、有效期和复制配置移到高级设置；Workbuddy 暂保留手动接入。

## 实现

客户端检测常见应用、CLI 路径或已有配置。检测到配置不代表应用正在运行，界面明确显示“已找到客户端或已有配置”。显式连接操作创建独立只读凭证，保存到原有按知识库/连接隔离的钥匙串，通过 stdin 将配置传给随包 Python 工具，不把凭证放到命令行或日志。

配置路径默认 Codex ~/.codex/config.toml、Claude ~/.claude.json；尊重客户端进程环境中的绝对 CODEX_HOME / CLAUDE_CONFIG_DIR。Codex 配置格式依据 [OpenAI 官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)，Claude 用户级配置依据 [官方 MCP 文档](https://code.claude.com/docs/en/mcp)。GUI 未继承的终端环境不能自动推断，特殊安装路径或配置位置可继续手动接入。

Codex 在原文末尾添加本连接唯一的受管区块，使用已有 tomli 校验修改前后其他设置完全相同；不接管同名非受管条目。Claude 合并 mcpServers 中本连接的条目，保留其他根字段及其他服务；同名不同配置拒绝覆盖。解析失败、冲突或无法安全合并时保留原文件并提示高级设置。

现有配置先保存为同目录唯一 .pka-backup 文件，权限 0600；新配置 0600、fsync 后原子替换。拒绝符号链接、非常规文件、不同用户拥有的文件和过大配置，非阻塞锁阻止本产品同时写入；写入前及检查完成后复核内容。备份可能含其他服务的凭证，应保留在本机私有目录，不进入知识备份或版本控制。

安装后以官方 MCP SDK 启动本次知识库 stdio 入口，发现工具并执行一次只读检索，不调用模型。不启动其他服务、不运行 Agent 登录或重启命令。失败时仅在文件仍等于本次写入结果时恢复原文件；若其他程序已修改则不覆盖，并报告状态未确认。这仍无法与不遵守锁的外部编辑器建立跨程序事务。

列表提供接入、检查连接、断开。断开先移除当前选择 Agent 中本连接的匹配配置，再撤销独立凭证；两步不具备跨文件/API 原子事务，部分成功时明确提示配置已移除而撤销/刷新未确认，用户可刷新或在高级设置处理。凭证创建成功而安装失败时保留连接供重试，不重复创建。

“配置已安装，知识库服务检查通过”指本地协议和授权检查，不表示运行中的 Agent 已重新加载配置，也不是模型回答质量。用户需在 Agent 中重新加载 MCP，部分客户端需要重启。已手动配置的同名服务可能需要手动整理后才能进入受管模式。建议每个 Agent 独立创建连接。
