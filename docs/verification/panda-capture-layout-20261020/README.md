## 交互约定

1. 队列全部成功结束且没有待处理／处理中项时，五秒后熊猫回到初始位置；新增或重试任务取消旧计时。用户明确要求失败项存在时保留异常提示，直到失败项被处理或移除。移除失败项后，剩余项全部成功才开始计时。
2. 原生文本框获得输入焦点即隐藏占位提示，空文本失去焦点时恢复提示。
3. 左侧为220pt高的资料编辑区与知识库／项目选择；右侧为整理队列。大窗口使用双列，最小窗口允许页面纵向滚动。
4. 队列按待处理、处理中、已完成、失败四个标签筛选并显示数量。列表内部固定300pt高度，支持纵向滚动条；切换标签回到列表顶部。
