# 存储分类精简与悬浮气泡

仅调整存储设置的展示，不改变原始十类统计、数据库、文件或统计范围。按用户要求同步将占用条、图例、明细合并为五类：

| 展示分类 | 原始统计 |
| --- | --- |
| 应用程序 | 应用程序 |
| 文稿文档 | 文档与正文、图片 |
| AI 分析 | AI 分析 |
| 数据索引 | 索引、本地模型、数据库与设置 |
| 缓存 | 缓存与日志、库内备份、草稿与待整理 |

每个原始类别恰好计入一次，合计及占比保持不变。说明文案也同步简化，缓存说明保留“库内备份与待整理资料”，不宣称这些内容可删除。

原系统 help 提示替换为页面内连续轮廓气泡，显示类别和该类大小。气泡尖角的横坐标始终等于对应色块的中心，不使用鼠标在色块内的位置。常规位置气泡整体居中；靠边时仅移动气泡主体避免截断，尖角仍精确指向色块中心，最多借用卡片20点内边距。图例悬浮也可显示该类气泡，便于查看很小的色块。气泡不参与布局、不截获鼠标，不推动正文；离开页面清除悬浮状态。

使用原生 SwiftUI smooth 0.16秒淡入淡出与4点位移，类别切换平滑移动，系统减少动态效果启用时不播放移动动画。没有添加第三方依赖或清理功能。

## 测试

StoragePresentationTest.swift 验证五类映射不重不漏、中文名称、分组总量、空状态、条宽总和，以及300／520／614／1000点宽度、10亿字节对1字节的极小末尾色块中，气泡尖角中心一致及边界避让。原 StorageTest 回归保持通过：文件／SQLite页面合计、WAL、只读、历史库、硬链接、符号链接、损坏回退与取消。

原生交互与截图、优化构建、签名及发布状态见 runtime-storage-groups.json。
