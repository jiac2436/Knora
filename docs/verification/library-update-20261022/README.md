# 更新知识库：统一入口与重新分析范围

知识库概览的“全量分析…”与“生成／更新概览…”合并为“更新知识库”。沿用既有分步任务、预览确认、停止与恢复机制；旧概览任务仍运行时，入口继续显示其进度，避免另起收费任务。

弹窗“重新分析”默认未勾选，说明按钮解释两种模式：

- 未勾选：复用有效结果，只分析从未产生完整分析结果的文章。以前分析过但当前已过期的文章跳过，统计与资料明细分别标记，不参与新的概览请求或摘要索引更新。
- 勾选：所有文章均重新分析，不能因为旧结果仍然有效而被 Worker 自动复用；正在执行的相同输入分析允许按既有规则接续，不重复派发。
- 全部文章均为过期结果且未勾选时，提示勾选重新分析，禁用开始，避免发送空概览。

移除预览中的 AI 调用与预算明细、重新预览按钮及任务页的预算折叠区。失败后保留检查资料范围的恢复入口。开始更新、停止后续步骤及重新检查资料均不带尾部省略号。后者表示新预览，仍需点击开始才授权调用。

## 本次 token 用量

只在任务完成且模型回执完整时显示输入、输出与合计 token。仅统计该父任务实际创建的单篇分析及新概览步骤；复用结果不计费重算。长文最终产物已经聚合分段与合成用量，仅计一次。缺失、零占位、非法回执、外部已在运行的独立分析或非完成任务不显示数字，不把预留预算当作实际用量。未产生新调用的完整任务可显示 0。此值是模型报告用量，不换算货币或声称与供应商账单完全一致。

## API 与兼容性

`POST /v1/domains/{id}/analysis/full/preview` 与 `/jobs` 增加可选严格布尔值 `reanalyze`，默认 false。默认策略由“补做未分析及过期”改为“仅补从未分析”，这是本次明确要求的行为变更。预览摘要绑定模式，切换后必须重新读取对应预览；客户端取消／失效旧模式请求，迟到响应不能覆盖当前统计。

响应增加可选 `reanalyze`、`stale_sources`、`skipped_sources`；任务增加 `token_usage`（缺失时 null），资料状态增加 `skipped`。`stale_sources` 是更新前已过期数量，`skipped_sources` 是实际跳过数量。概览计划允许显式排除所选过期文章，完整依赖快照仍保留，任务中用户改动输入仍停止。

无数据库迁移，schema16 与插件1.0.5不变。新模式写入已有任务快照与客户端待确认请求。旧请求缺模式视为 false；已接受旧请求保持原幂等摘要，旧正在执行任务沿用冻结资料列表。未接受的过时预览需重新确认。备份恢复没有操作任务记录时，仍能从最终分析产物识别过期文章。

## 验证

- API／Worker／持久化、概览计划与长证据：110 项通过；补充确认跳过后新概览可读的回归通过。
- Swift：默认模式、自动刷新、旧模式晚到防护、丢响应后同 ID／同模式恢复，及既有确认、单飞、停止、身份／端点隔离、401／403、unknown 回归通过。
- 使用真实随包 Python／宿主／API／Worker、临时 SQLite 和只监听回环的合成模型验证：默认只补未分析、过期跳过且概览排除、勾选全部重做、模型回执汇总、重启结果与用量恢复；既有幂等、关键词索引、模拟503后重启不重播通过。真实模型调用为0，不读取用户库。
- 原生生产视图的隔离 Bundle：确认仅有统一更新入口；复选框默认关闭；说明可读；切换统计由4复用＋1分析＋1跳过变为6分析；开始后进入进度；完成显示模型回执用量。截图见同目录。
- 构建只有原有4项钥匙串兼容接口弃用警告，本次不修改该模块。

旧随包测试脚本依赖已停用的环境变量模型配置，首次验收因此返回未配置模型；新脚本使用当前私有启动 JSON 配置外置合成模型，不修改生产配置或凭证机制。

## 同时编辑的隔离

验收时另一个任务修改了 MacKernelHost.swift 并增加浏览器桥接代码，一度导致共享源码编译输入变化。正式候选改用独立源码快照：仅纳入本次3个 Swift 文件，其余文件逐个匹配上一正式发布的 SHA-256；MacKernelHost 在快照中恢复到已验收的精确摘要，未覆盖工作区另一任务的文件。快照及摘要在运行包记录中登记。后台仅同步本次5个文件，完整运行包19959个文件通过清单校验。

发布状态以 `runtime-library-update.json` 和 `apps/macos/release.json` 为准；测试通过并不代表已替换正式 App。
