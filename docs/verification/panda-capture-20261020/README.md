# 熊猫采集页验收

## 本次范围

- 采集页加入熊猫整理台：接收、读取、归档位置及失败提示，文件随熊猫移动，完成时收起文件并显示完成标记。
- 使用一次解码的透明 PNG 与 SwiftUI 动画，无新依赖、实时 3D 或额外模型请求；活动动画最高 24fps。离开采集页、应用不活跃、收起整理台或系统减少动态效果时停止循环动画。
- 保留文本／链接／文件采集，增加编辑区文件拖入支持。紧凑知识库和项目选择，新建入口移入弹出面板。队列显示处理中／完成计数和打开资料入口；失败项从阅读器查看原因并重试。
- 上传保存与解析完成分开展示，未识别出文字的文件不会显示绿色完成标记；后台没有精确页数或索引阶段事件，因此不编造页数、总进度百分比或独立索引动画。
- 修正本地采集状态请求的 `local|owner` 标识，统一刷新 PDF、文档与网页。页面内每4秒刷新待处理状态（请求耗时另计），完成后停止；打开采集页时核对已有条目。离开页面取消轮询，Worker处理继续。
- 请求返回后检查账户、连接及条目归属；网络失败保留原件并显示状态不可用，后续刷新恢复。沿用原队列格式，无数据库／API迁移。

## 验证

- `CaptureWorkbenchTest.swift`：12个状态边界，以及生产 CaptureModel 的模拟 API 集成：本地PDF和网页从running到completed，完成停止轮询、队列持久化、断网保留、其他知识库条目不发请求。
- 使用独立测试 App、临时队列、URLProtocol 合成响应渲染实际 SwiftUI 视图，核对1100×900与950×680内容尺寸。小窗口列表可滚动，提交栏始终固定；顶部可收起整理台。
- 完整优化构建、严格签名验证、19,936个运行包文件／链接校验、打包素材逐字节一致性通过。
- SwiftUI源文件相对上一版仅修改 App.swift、Model.swift、Workspace.swift，新增 CaptureWorkbench.swift。后台运行包保持已验收的模型配置版本，摘要 `08923e76f569559a58b8524a05d95e1053e4dc10458a5fe0409348f85aefa4d0`。
- 未访问或修改真实资料／凭证，未调用收费模型；本轮没有重新测试真实OCR或网站抓取质量。减少动态效果、拖放及打开资料按钮完成编译／代码检查，未声称完成全部真人鼠标操作验收或CPU性能基准。
