# 轻量基础客户端与官方扩展验收

## 本次交付

以 A 图标正式版为基线，保留 SwiftUI／AppKit、共享本地内核和云端 AI 执行代码。拆出语义搜索、文字识别、文档解析三类官方扩展；设置新增扩展功能页，支持离线导入、HTTPS 下载源配置、进度、取消、启用、停用及卸载。暂无生产下载服务器，当前使用配套离线包。

候选 App 逻辑文件大小为 **112,929,643 字节（112.9 MB）**，上一完整 App 为 **1,124,447,905 字节（1.124 GB，包含原先单列的模型）**，基础安装体积减少约90%。APFS 文件分配长度分别为119,955,456与1,171,169,280字节；克隆／共享块使其不能视作独占物理空间。数字来自本机一次构建，不是内存测量。

| 扩展 | 压缩包字节数 | 安装字节数 |
| --- | ---: | ---: |
| 语义搜索 | 95,001,334 | 239,428,074 |
| 文字识别 | 239,424,527 | 781,178,000 |
| 文档解析 | 9,016,319 | 21,837,710 |

基础包保留必要 Python、Pillow、PDFium、HTTP／数据库／MCP 等依赖。扩展之间保留部分重复辅助依赖，便于独立停用和卸载；全部安装的总空间不保证小于旧完整包。存储统计会将扩展代码、模型及安装暂存归入对应已有分类，不重复计数。

离线包交付目录：`apps/macos/dist/扩展包/`。操作说明见[轻量客户端与扩展使用说明](../../轻量客户端与扩展使用说明.md)，实现边界见[方案第10节](../../design/轻量基础客户端与可选扩展方案-2026-10-23.md)。

## 实现与兼容

- 内置 catalog 固定体系结构、版本、包长度、完整 SHA-256、文件清单摘要和解压长度。安装拒绝错误平台、坏包、符号链接、路径穿越、重复条目、特殊文件、超大解压及不安全目录，使用私有目录和原子发布。
- 每次进程启动固定选择并验证全部文件；Host／Worker持有共享 lease，卸载使用排他锁，使用中的扩展等待退出后删除。停用和卸载不删除原文、分析结果、历史版本或其他知识数据。
- 缺扩展任务在数据库继续使用 pending＋错误标记，API派生 waiting_extension，防止破坏旧schema。恢复仅处理本地任务，不重发模型调用。等待期间手动编辑会取消自动解析，明确重试后旧版本仍保留；混合PDF保留可读页。
- schema16、插件1.0.5和内核契约1不变，无数据库迁移。扩展安装记录为独立version1 JSON。旧完整App回退仍可用原内置引擎，不处理新扩展目录。MCP新增可选精确模式，默认bridge参数形状保持兼容。
- 新轻量包默认不安装扩展，不自动下载。原有资料与结果保留；需要重新执行对应能力时由用户手动安装。

## 当前边界

首版仅macOS arm64、Python3.10，沿用本机ad-hoc签名。生产CDN、独立远程版本目录、断点续传、逐引擎独立进程／空闲释放、干净设备矩阵、Developer ID公证和商业许可证核对尚未交付。HTTPS下载通过模拟传输验证，不能当作真实下载站验收。引擎仍复用现有Host／Worker，安装和启停需重启生效；拆包不承诺推理峰值内存降低。

正式发布结果将在发布器预检与替换成功后追加；本文件的构建与测试结论不代表此前已替换正式App。
