# AI 初始状态与完整浮层修复（2026-10-21）

## 问题与改动

首次打开时原代码用空的内存结果数组直接判断未分析，状态读取依附在概览组件上且排在标签读取后。现增加按资料 ID 和加载代次隔离的 loading / ready / failed 状态；只有成功读取且结果为空时才显示未分析，加载中显示圆圈，失败提供重读状态。旧代次响应不能覆盖新状态，解析 jobs 与 artifacts 后原子提交。

分析状态观察任务移到正式阅读页稳定容器，先读取 AI 状态，不随概览浮层隐藏而取消。收起栏和展开层整体移入 overlay，不占用正文布局高度；共享坐标系同时覆盖工具栏和浮层，尖角保持对齐。

顶部按钮：已有结果时打开概览，再次点击隐藏；分析运行时可隐藏或显示进度栏，不打开另一张详情 sheet，也不停止任务。未分析资料仍先预览并确认；底部重新分析仍需逐次确认。概览头部箭头继续切换内容展开，运行中保持状态栏模式。

正文区域先按自然内容测量，短内容自适应；超过 240 点时滚动，避免长结果越界。移除重新分析按钮上方的分隔线，保留头部与正文之间的分隔。

## 验证

`apps/macos/scripts/AIOverviewFloatingTest.swift` 使用隔离临时库、合成资料及 URLProtocol 模拟 API，覆盖：

- 加载中、确定无结果、确定有结果、读取失败。
- 同一资料加载代次改变后，旧请求返回不能标记新状态为 ready。
- 有结果/无结果/显式重新分析的操作路线、分析中显示隐藏窗口。
- 1100 / 600 点宽度下隐藏、收起栏、展开层三种状态的正文 CGRect 完全一致。
- 展开内容自动测高、窄窗口标签换行、新任务自动收起。
- **实际挂载正式 KnowledgeView**，验证未知状态出现后由稳定观察任务读取已保存结果，并生成 startup-loading / startup-restored 截图。

完整优化构建、严格签名、运行包 19,957 个文件及链接校验通过；新建分析任务的唯一调用仍在确认动作内。未发送模型计划/创建任务请求，未使用真实厂商调用或修改用户资料。

限制：未自动完成鼠标点击、长内容滚动和 PDF 原件上的浮层交互验收。截图为合成资料。未针对真实用户资料执行重新分析。
