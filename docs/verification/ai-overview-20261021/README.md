# AI 概览状态与气泡界面（2026-10-21）

## 改动

- 移除概览中的“编辑标签”“分析详情”“原文依据与分析说明”三个入口；既有阅读器标签管理、顶部分析任务详情仍可使用。
- 所选资料的进行中任务优先于旧分析结果。等待、正文/图片分析、多步进度、更新检索均显示在收起的概览栏；处理中不渲染展开按钮，正文也受同一状态控制。进入处理中自动清除展开状态，完成后恢复箭头，由用户展开。
- 右侧增加原生圆弧旋转动画；只在任务活跃时存在，支持系统减少动态效果。按真实任务步数显示进度，不推算百分比。
- 卡片一体绘制尖角和边框，实时测量分析按钮与卡片位置；窗口缩放、侧栏变化时重新定位，边缘有安全限幅。独立详情页不显示尖角。
- 上一项“每次分析都确认”的修复保留在本候选包中。

## 动画参考

已浏览用户指定的 [LottieFiles loading 列表](https://lottiefiles.com/free-animations/loading)，选择 vinaya ravindran 的 [loading 圆弧动画](https://lottiefiles.com/free-animation/loading-cRFDwhTyO8)作为视觉参考。本实现使用 SwiftUI 原生圆弧、旋转和系统减弱动态效果设置，没有下载或打包其素材，也没有新增 Lottie 播放器依赖。

原生截图覆盖等待、重新分析、索引、完成及 900 点窄窗口。已查看截图，尖角在宽窄布局中对准顶部分析按钮，分析中只显示状态与加载圆弧。常规沙箱无法完整访问窗口服务，正式截图通过放行窗口服务的隔离测试程序产生。

限制：原生点击工具连接超时，未完成鼠标/键盘交互验收；“展开锁定”由状态回归与渲染分支检查验证，未发送真实厂商请求，未修改用户资料。尚未做动画帧率/能耗基准。
