## 范围与行为

仅调整“模型与 AI”中直连模型的厂商 API Key。Owner 启动凭证既有私有文件方式保持；Agent 凭证和独立外部网关凭证的保存方式不变。查询外部网关的“已保存”状态改为静默读取，设置页不因状态检查请求授权。

模型密钥保存到当前 macOS 用户的 `Library/Application Support/local.pka.knowledge-inbox-state/model-credentials/`，目录 0700、文件 0600。文件名由知识库凭证服务标识生成，与密钥内容无关；内容为带版本的 JSON 明文。用户已明确接受文件权限保护弱于钥匙串的取舍。没有使用内置固定密钥来伪装加密。

首次读取优先使用私有文件。没有文件时只调用旧钥匙串的无交互读取：可读取则原值迁移；被拒绝或不可用时不请求密码，设置提示重新填写 API Key。新保存与替换直接写文件，不写钥匙串。不同知识库按原 credential service 隔离；配置代次和凭证 generation 的业务规则保持。

清除配置写入无密钥的删除标记，阻止重启后从旧钥匙串重新导入。旧钥匙串条目不自动修改或删除，避免清除过程弹出系统授权；必要时用户可在系统钥匙串中自行管理旧条目。安全文件元数据异常时拒绝读取/覆盖，也不回退旧密钥；仅载荷损坏且权限正确时允许重新填写修复。
