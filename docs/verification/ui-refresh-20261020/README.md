# Mac 客户端界面优化验收（2026-10-20）

本次只调整客户端视觉与交互布局。后台运行包沿用已验收的模型配置版本，清单 SHA-256 为 `08923e76f569559a58b8524a05d95e1053e4dc10458a5fe0409348f85aefa4d0`，共 19,936 个文件及链接。数据库、API、模型凭证和资料格式均不变，无迁移步骤。

## 改动

- 石墨灰背景、系统字体、统一文字层级、输入框、按钮和悬停状态；危险操作保留红色。
- 52pt 导航栏、56pt 顶栏、36pt 阅读底栏；知识库切换保留在底部。
- 阅读工具栏保留问答、分析、视图切换、更多操作和证据入口；标签、图片、重读、Markdown、PDF 扫描及字号操作进入更多菜单。
- AI 概览默认折叠，展开区域有界；部分覆盖警告在折叠态仍保留提示。
- 正文与标题对齐；保留 WKWebView、PDFKit 缓存和搜索定位逻辑。编辑器取消过大的最小高度。
- 采集页整理为编辑区、保存位置、采集队列和固定保存操作。
- 设置改为侧栏导航；直接模型与外部网关配置使用明确字段标签。
- 窄窗口用独立证据面板并提供关闭按钮；搜索列表高度跟随结果数量。

## 验证方法

1. 使用 `scripts/build.sh` 完整编译优化版客户端，验证全部运行包文件和签名。
2. 现有 `WebTextReaderTest.swift` 五项通过；`LocalAIProductTest.swift` 通过。前者的部分定位断言以流程执行及无崩溃为准，额外通过界面检查确认合成文本“专注阅读”能定位并高亮。
3. `LocalUITestApp.swift` 使用生产视图、独立临时 HOME 与凭证命名空间。创建“设计验收”库，保存合成 Markdown 笔记与两页 PDF；不编辑用户资料、不保存真实模型密钥、不调用外部模型。
4. 实际检查 950×680 内容区域下采集保存、阅读/编辑切换、搜索定位、PDF 原件/文字及页码导航、模型配置表单与外部网关兼容入口。
5. AI 折叠行为通过代码审查；临时库已准备合成 artifact，但测试包重启后 UI 工具无法绑定，动态展开截图未完成。最后两处证据关闭按钮和搜索列表高度修正已完成最终构建与代码检查，未重复截图。

## 边界

正式候选包读取既有账户凭证时停在凭证读取阶段，系统授权界面不允许由自动化操作。未修改钥匙串权限、凭证或登录逻辑；界面验收使用隔离测试库。真实账户启动授权需要用户在本机完成。本轮不宣称 OCR、网页抓取或模型回答质量有所变化。

最终构建、二进制摘要和各检查结果以 [runtime-ui-refresh.json](runtime-ui-refresh.json) 为准。
