# M3：平台依赖隔离

状态：工程验收完成；未替换正式 App。M4 正式采集业务迁移、M5 同版整包与真实模型质量验收仍未完成。

## 本批实现

- Python 增加 `platform_support` 小型能力契约与明确的平台选择。目录/运行包、私密文件/锁、独占原子发布、受管进程分别通过适配层调用；既有业务入口、锁文件名、权限、数据库与备份格式保持。
- `local_paths`、`local_runtime`、Host/Worker、端点发现、模型切换门禁、文件/图片保存、迁移快照、备份/恢复与旧库导入复用上述能力。`fcntl`、`ctypes`、`O_NOFOLLOW`、所有权、信号和 `pass_fds` 实现收在平台目录内。
- MCP 配置与授权规则留原模块。插件私密启动器改调用共享 `agent_launcher`，固定解释器/MCP 脚本/环境字段，只继承允许的基础环境；凭证读取及 exec 经平台实现。插件托管文件仍须精确0600和摘要匹配；并发修改、检查失败和回滚规则保留。
- 原生增加 `PlatformContracts`、桌面操作和库目录协议，Keychain、宿主生命周期、库指针私密 I/O、备份/安装 CLI、路径/进程、飞书 CLI 与 Apple Vision 收在 `Mac*.swift`。保留 `LocalService`、`LocalLibraryStore`、`LocalBackupTool` 兼容名称，页面和缓存状态机未重写。
- 飞书受限命令执行可注入替身，返回有界 stdout/stderr/退出码，支持取消、超时和大小阻断；业务错误仍由飞书层映射。清理无关环境，保留本机授权配置与显式 profile 参数。OCR 实现沿用图片真实性/像素限制及文字上限；有效图片在 OCR 不可用时继续保留。
- 启动私有信封新增客户端契约/schema版本，Host 在迁移和身份修改前拒绝不兼容版本。就绪事件与 `/health` 新增同一份内核版本、契约、schema、平台、CPU、清单摘要和能力；不含密钥及本地路径。原生校验元数据与本地清单身份，缺失或不匹配时退出受管宿主。

详细接口和未来平台边界见 [平台说明](../../../services/api/app/platform_support/README.md)。
