# 上次文章与阅读位置恢复

重启后打开上次成功阅读的文章，并恢复正文段落／图片锚点或 PDF 页码与页内位置。没有记录时沿用最近文章；已删除或不可访问的记录不会卡住启动。主动打开的文章、搜索定位与外部文章链接优先于启动恢复，迟到的详情响应不能覆盖新选择。

## 保存与恢复

每个本地资料库的数据目录新增 `reading-session.json`，schema version 1，文件权限0600。只含文章／知识库ID、正文内容摘要指纹、段落原文UTF-16偏移、相对位置、PDF坐标和PDF原件／文字模式，不含正文、标题、链接或任何凭证。不改变知识数据库schema16、API、运行包或插件契约。旧安装没有此文件时正常打开最近文章，无迁移步骤。

正文通过已有来源映射记录可见段落或归档图片；每帧合并滚动事件，只更新小型内存状态，约300ms合并写盘，切文及正常退出时同步刷新。首次恢复期间响应布局和图片高度变化；用户滚动或搜索后停止旧锚点约束。内容指纹变化时丢弃旧偏移，使用原相对进度，避免把已变化的正文当作同一段。

PDF使用PDFKit的原生当前位置；等首次布局和自动缩放完成再定位，避免提前设置的目标被重置到页首。原件与文字视图分别保留位置。阅读器实例按文章隔离，不复用上一PDF的协调器。

首次加载不依赖上次文章是否位于最近50条之内，直接读取该文章详情。会恢复其知识库范围；文章已移动时以当前所属范围为准。404清理失效记录并回退；临时连接失败不删除记录。删除当前文章时清除其阅读记录。切换独立本地库时刷新旧文件，并绑定新库文件。

记录损坏、版本不支持或文件为符号链接时跳过恢复、保留原文件，不阻止基础阅读；正常阅读状态仍在本次运行中保留。非正常强制结束可能丢失最后约300ms的位置；正常退出会保存最新已收到的位置。该设备级阅读状态不纳入知识资料导出，不声称跨设备同步。

## 验证范围

`ReadingSessionTest.swift` 使用临时目录、内存HTTP响应、合成正文及合成PDF：私有文件往返、立即退出刷新、库隔离、旧文章迟到事件、无效／损坏／符号链接保护、详情恢复、404、外部链接优先及切文竞争；真实WKWebView重新创建恢复、窗口变窄、延迟高度变化、搜索定位优先；PDF真实布局、页码与页内坐标、后续滚动更新。

`ReadingResumeUITest.swift` 使用生产 KnowledgeView、隔离Bundle及临时状态文件。最近列表首条故意不是上次文章，以验证自动恢复；滚动后退出再开同一测试App，核对文章与位置。所有资料均为合成，无真实模型或用户库访问。

候选构建、原生验收、签名与发布状态见同目录JSON记录和日志。发布前必须确认正式客户端已退出，不能强制结束用户进程。
