# 验收资料目录

2026-11-06 按维护者要求清理了工作区中的历史验收截图、录屏、运行日志、UI 状态快照、AI 分析和检索输出。保留功能说明、测试脚本、构建摘要、依赖来源清单及测试必需的合成输入。

`ai-product/samples.json` 是质量验证脚本使用的合成测试语料，不是用户知识库或已生成的 AI 结果。

历史构建 JSON 中的原产物路径、测试日志路径和当时的校验结果用于追溯，不表示被清理的截图或原始输出仍可获取。原始产物删除后，没有重新改写验收结果或伪造新的通过状态。

清理范围和复核结果见 [项目资料清理记录](../项目资料清理-2026-11-06.md)。新的本机截图、录屏、运行库和模型输出应留在本地临时工作目录；需要公开的示例应先使用合成内容并完成审核。

历史 `.cjs` 视觉检查脚本是可选开发工具，不是 App 运行依赖。它们通过标准 Node 模块解析加载 `playwright` / `sharp`；需要时在独立工具目录安装这些开发工具并设置 `NODE_PATH`，不依赖维护者电脑的缓存路径。常规插件验证优先使用 `apps/extension` 中的 `npm test`、`npm run check` 和 `scripts/test-browser.py`。
