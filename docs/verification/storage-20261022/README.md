# 设置中的存储统计

## 界面与范围

设置新增“存储”。上方为当前 App 与所有受管理本地资料库的文件大小总计、分类占用条与颜色图例；悬停分类显示名称与大小。下方逐项列出应用程序、文档与正文、图片、AI 分析、索引、本地模型、草稿与待整理、库内备份、缓存与日志、数据库与设置。可手动刷新并显示更新时间，不提供清理／删除操作。

沿用当前设置面板的石墨灰底、系统字体和按钮样式。占用条按各类别实际大小占比绘制，不为小类别人为放大；图例和明细使小分类仍可查看。长内容随设置页滚动。扫描与数据库统计在 utility 后台任务执行，离开页面可取消，刷新期间保留上一份结果。

扫描唯一当前 App 包、旧默认及恢复后的所有本地资料库管理目录，以及本客户端设置、持久缓存和日志目录。包含历史版本及回收站里仍保留的数据。不扫描旧版本 App／源码／归档目录、外部备份、用户原件所在任意文件夹、系统临时目录或其他应用目录。不跟随管理目录中的符号链接；硬链接按文件标识去重，链接自身仅计链接文件大小。

## 统计口径

使用逻辑文件长度（与 SQLite 页面字节可相加），并在页面明确标为“总文件大小”。不声称是 APFS 独占物理空间或可清理空间；压缩、稀疏文件、克隆和共享块可使磁盘实际分配空间不同。

- 当前 App 的可执行文件、资源和 Python 等内置运行环境归“应用程序”；已知 runtime/model 与 runtime/ocr-models 单独归“本地模型”，不在 App 类重复计数。
- assets 文件原件归文档、assets/images 归图片；capture-queue／staging 归草稿与待整理，backups 归库内备份，模型缓存单独归模型。
- SQLite 用系统 SQLite3 的只读连接、query_only 与有界锁等待查询 dbstat，不读取用户业务行或凭证内容，不执行清理、VACUUM、checkpoint、迁移或索引重建。原文与历史版本等表的页面归文档；图片元数据／识别文本归图片；AI 产物／主题／问答表归 AI 分析；检索表、向量和 SQLite 查询索引页归索引。页面按完整页长度统计，包含页内空隙。
- 当前有效页可位于主文件或 WAL，只计一次；其余空闲页、旧 WAL 帧、SHM、数据库元数据与未知表保留在“数据库与设置”，因此各类之和等于测得的文件总大小。
- dbstat 不可用、数据库损坏／繁忙或写入期间测量容器小于有效页总量时，整份数据库文件继续计入“数据库与设置”，显示无法分类的提示，不伪造 AI／索引大小。文件无法读取会明确提示部分统计并将标题改为“已统计文件大小”。统计为一次读取快照；写入并发可能造成少量瞬时变化，支持刷新。

## 兼容性

仅增加 macOS 原生只读扫描及设置页，不改变业务接口、数据库结构／schema16、插件1.0.5和持久格式；无需数据迁移、不增加第三方依赖。系统 SQLite3 不支持 dbstat 时按整库回退。完整候选 App 复用上一版已验收运行包，摘要与 API／Worker／网关保持不变。

## 验证

StorageTest.swift 使用独立临时 home、App 和 SQLite 数据库，验证已知文件总字节数与分类合计相等、内置／缓存模型不重复计数、多个历史资料库、原件／图片／分析／索引、草稿／备份／日志、硬链接去重、外部符号链接不遍历、旧 App／外部备份排除。WAL 写连接保持打开，确认分类可用且扫描前后主数据库与 WAL 内容相同；另覆盖损坏数据库回退、空目录和取消。

构建、签名、原生设置交互与发布状态记录在 runtime-storage.json。UI 验收仅使用合成数据，不读取用户文章或凭证。

## 发布完成

原生设置页截图为 storage-overview.png／storage-details.png，刷新与底部说明可见。优化构建与严格签名验证通过；完整候选包扫描为 1122687403 字节，与独立 Python lstat 合计一致，应用程序 995873916 字节、本地模型 126813487 字节（仅 App 包）。单次扫描约0.57秒，为一次观察而非性能承诺。

发布预检确认正式客户端已退出，经发布器更新唯一 `apps/macos/dist/知识收集箱.app`。旧版归档于 `apps/macos/archive/20261022-183614`。发布后再次确认唯一 App、二进制／运行包／源码摘要及原版 Logo；用户资料未修改。
