# 知识库选择与首次采集
- 移除切换菜单中的“全部资料”；连接成功后，浏览范围使用已恢复的知识库。
- 知识库与项目选中标记根据当前浏览范围互斥显示。
- 标题、日期和标签切换保留当前范围，分页全量读取也带知识库或项目过滤。
- 无知识库且有待发送资料时，先重新读取知识库列表，仅确实为空时创建“默认知识库”，选中后继续发送。正在发送时禁止重复提交。
- 默认库创建失败时抛错，保留草稿转成的队列供重试。创建成功后保存当前选择。
- 新建知识库也同步选择范围。
- 合成 API 测试覆盖：启动范围同步、标题和全量请求过滤、已有库不创建、后台已有库时刷新复用、创建失败、默认库创建选中、重复调用不重复创建；原采集队列和状态轮询回归通过。
- 无数据库结构或 API 契约变更，无需迁移；默认知识库通过现有创建接口生成。
- 未操作用户数据，未真实上传资料；菜单鼠标操作尚未单独自动验收。
