# 阅读页布局
- 顶部工具栏依次为列表开关、文档类型、标题与版本、阅读操作。长标题截断并可悬浮查看。
- 移除正文独立大标题；正文容器上边距20点改为4点。
- 普通阅读和PDF原件视口上下18点使用系统ultraThinMaterial渐变蒙版。装饰不接受鼠标事件，不模糊整篇页面。
- 侧栏宽200–360点，8点拖拽区域，保存宽度和收起状态；提供无障碍宽度调整操作。
- 使用合成长文渲染常规1280×850、最小898×680、宽侧栏和收起状态。类型检查、原生构建、运行包验证均通过。
- 复用现有正文与PDF实例，未添加内容刷新请求、计时器或动画循环；未进行帧率基准。
- 菜单及拖拽尚未执行真实鼠标自动化测试。整窗截图中的WKWebView合成层可能保留缩放前的画面，网页正文尺寸另外通过DOM测量和WebKit快照核对。
- 无数据库或API变更。设置新增readerSidebarCollapsed、readerSidebarWidth，缺失时使用展开/248点。
