当前保留已有概览弹窗入口，没有重构应用主导航。单篇缺失分析的统一授权自动补齐仍属于后续编排；本轮没有新增该能力，不能把概览生成成功等同于全部资料已分析。真实资料仍沿用现有单篇分析及知识域更新流程。

## 2. 防闪烁与并发加载

- 三个页面保持挂载，只切换可见与交互状态；隐藏页不能接收点击、键盘交互或无障碍焦点。不以重建整个页面来切换标签。
- 概览、分类元数据、统计、各分支文件分别缓存，默认有效期 20 秒。缓存有效时切页不重复请求，同一资源请求合并，不用全局 loading 锁阻塞其他页面。
- 首次读取显示固定空间占位；已有结果后台刷新时继续显示旧内容，完整新结果到达后单次替换。目录分页先组装完整元数据，文件仅在展开分支时分页读取。
- 已加载多页文件的刷新保留原已读范围，完整重读后替换，避免先缩回第一页再逐页长出。
- 服务地址、凭证或知识域变化时取消旧读取并清空跨身份缓存。读取代次、资源请求标识与取消状态共同校验，取消后晚到的旧响应也不能覆盖当前结果。401/403 会清除本页敏感缓存。
- 授权失效或配置不可用时显示明确的重新连接页面，禁用更新和切页入口，避免无请求却永久停留在加载占位；重新连接只读取状态，成功后恢复浏览。
- 分类修改或任务完成使缓存失效；失效先保留可见快照，再读取当前选中页。返回分类页或重新展开分支时检查新鲜度。
- 分类与文件使用稳定标识，多归属文件以分支与文件组合标识。局部原文阅读不改变主阅读器选中项，也不退出概览。

缓存是页面浏览体验机制，不能提供跨请求事务快照。分页期间资料变更时去重并允许刷新；各页有各自读取时间，不承诺三个页面总在同一数据库事务内读取。

## 3. 数据契约与兼容性

新增目录、分支文件、统一信息与概览引用解析四类只读 API，详见 [接口说明](domain-library-api-20261015.md)。固定 App 范围并校验 owner、知识域、当前原文版本及当前有效产物，不扩大 MCP 授权。

当前域问答传递真实 `domain_ids`；分类问答限定该分类及后代的去重文件，Worker 在发送及发布前重验范围。会话历史按实际范围隔离；旧无范围请求及历史保持全库语义。详见 [问答范围契约](../../design/知识域问答范围接口-2026-10-15.md)。

存储显示“已统计数据量”：记录的附件大小、当前正文 UTF-8 数据量、有效 AI 产物 JSON 和当前向量数据量。完整物理磁盘占用返回未知，不把共享 SQLite 大小均分给知识域，也不把此数称为 RAM。语义索引关闭与索引失败、缺少有效产物分别展示；索引可用不代表回答准确。

数据库仍为 schema **14**，本轮不新增表或迁移，不改变备份格式，不添加依赖。独立 `ai_gateway` 本轮无代码或提示词变更，无需为本轮界面升级重启网关。
