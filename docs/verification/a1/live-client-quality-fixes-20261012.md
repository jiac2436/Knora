## 修复方式

1. 有效长引用连续细分为最多1000字符窗口，绑定原始证据与准确偏移，单篇原产物不重做。
2. 发送前按引用预算分批：叶与中间9000字符/10来源/40证据，最终根18000/20/80。长资料完整窗口进入多个叶批次；中间选择只保留有界节选，丢失引用的完整子摘要退出事实背景，依赖仍保留以检查变更。
3. 网关v2.6启用分层思考核对，max_tokens=16384，最终正文仍500/800硬上限；写作目标300/480留余量。原文输入按来源、原始块与原文位置连续排序，避免选择顺序打散指代。reasoning_content不返回或保存，单篇模式不变。
4. bounded-attribution-v3-reasoning版本参与新复用键，旧错误代节点不用于新叶复用；新模型结果必须通过原文与结构校验，未知/失败不自动重试。
5. 单次分析进度、部分覆盖排除原因和预算不足时同一确认授权已修复；网关优先用start.sh启动，避免遗漏:create_app。
