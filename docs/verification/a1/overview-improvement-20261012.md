# 概览压缩与重复主题加工优化

日期：2026-10-12。范围来自用户“尝试继续完善”：处理真实验收发现的概览重复和主题重叠加工成本。本批零新增模型调用，未访问或升级用户知识库。

## 改动

### 1. 全域计划省略完全重复的自动候选分支

先按Owner、知识域和app/shareable范围确定有效成员集合，再比较各主题。自动候选与人工主题的可见成员完全相同、且候选未改名固定、未设父层级、未人工调整成员时，全域计划省略该自动候选的重复加工。

- 不删除主题、标签或成员，不更改分类归属。
- 人工主题均保留；候选经人工改名、设层级、编辑成员后保留。
- 不合并部分重叠、子集/超集或不同成员集合，避免因省费用改变知识覆盖。
- 未归类资料保留；权限、未分析和原文失效检查沿用原机制。
- 显式选择自动主题做分析，仍独立加工；全域构建不承诺同时刷新被省略的候选概览。
- 旧任务按其原冻结步骤继续，新建任务必须用新预览hash；不重置累计预算。原来有9步的已授权任务不会被偷偷改成3步。

独立回归：两个人工主题、三个完全同成员自动候选，4篇资料全覆盖，只创建两次主题与一次域根（3次），不再是五个分支及四次合成（9次）。这是指定合成结构的调用数改善，不是所有知识库的节省比例或实际收费对照。

### 2. 动态概览写作目标

网关提示词版本为 `domain-node-evidence-v2.1`，根据本次提供的原文节选长度，写作目标为：`min(既有域500/主题800上限, 原文节选字符数, max(100, 原文节选字符数×60%))`。

概览指出主题与组织关系，要点只补充未覆盖的独立信息，限制只保留影响理解/使用的条件。短输入允许只有概览，不凑数量；事实、否定、条件和原文引用优先于压缩。

该比例是待校准的提示词目标，不是硬拒绝规则或模型效果保证。原来的结构、引用及硬字数校验保留，历史结果不会因新目标失效。不会用本地字符串相似度删掉可能有不同条件的观点。新版提示词真实压缩质量尚未复测。
