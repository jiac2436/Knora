日期：2026-09-20。状态：历史归档，记录当时的计划与验收范围；不是当前执行计划。当前工作和进度统一见[实施路线 v0.2](./实施路线-本地优先-v0.2.md)。

2026-09-30：后续本地优先、手动同步和云端增值服务采用[实施路线 v0.2](./实施路线-本地优先-v0.2.md)。本文为早期 M1～M3 计划，历史完成情况以对应验收记录及当前代码为依据，不作为新版架构已实现的声明。

依据：[产品需求](../prd/PRD-v0.1.md)与[技术方案](./技术方案-MVP-v0.1.md)。本计划以交付门槛安排顺序，未将人员数量、模型账号、云资源、移动端签名和测试设备视为已具备。

## 1. 交付定义

- M1：首个可运行工程闭环，含真实浏览器插件、移动 App 基础界面和真实 Agent 接入；允许以文本/片段为输入，明确尚未覆盖的 P0。
- M2：补齐原生分享、多媒体解析、混合检索和带引用问答，进入完整 P0 功能验收。
- M3：完成真机、质量、安全边界、故障恢复和试点准备，才称为可内测 MVP。

本次交付是上述阶段的方案，不创建项目脚手架、安装依赖、采购服务或部署环境。

## 3. 阶段验收演示

### M1：工程闭环

1. 用户创建“工作”和“生活”两个知识域，只授权 Agent 读取“工作”。
2. 插件保存一个技术案例片段，补充“给商品管理页参考”并关联项目。
3. 手机 App 刷新后显示云端已保存、部分文本、个人备注和未验证状态。
4. Agent 搜索找到片段，使用证据 ID 获取原文并引用；生活域资料和仅 App 可见资料不返回。
5. 用户追加“部分有效”及限制，后续检索返回这条个人经验。
6. 移动资料至未授权域、删除资料或撤销连接后，再次直接请求旧证据必须失败。

M1 验收记录必须另列尚未支持的图片/PDF/音频、双端系统分享、语义检索与生成式问答。不能用模拟供应商输出补齐验收。

### M2：输入与智能能力

对每种已声明格式分别执行成功、部分提取、失败和重试用例。iOS/Android 各至少一次真实系统分享；PDF 引用能定位页码，音频定位时间，OCR 能打开原图。卡片重跑不改变个人备注。基于原文、备注与卡片的检索均有对应测试。

### M3：内测门槛

| 项目 | 门槛 | 证据 |
| --- | --- | --- |
| 输入成功率 | 冻结支持集 ≥95%，失败原因完整记录 | 样本清单、逐项结果；不含未声明支持格式 |
| 内容完整性标注 | 已知登录页/验证码/标题页无误报全文 | 人工质量报告 |
| 引用定位 | 验收集中全部引用定位到对应版本 | 页面/时间/图像/文本回看记录 |
| 检索 | 有答案任务 Recall@5 ≥80% | 固定标注集、算法/模型版本与原始结果 |
| 权限 | 跨账户/域/撤销/删除/移动/文件路径零越权返回 | 自动化矩阵与真实客户端负向验证 |
| 可靠性 | 离线/重启/切账户/Worker 中断无静默丢失 | 恢复用例及任务状态记录 |
| 性能 | 小规模试点检索 P95 ≤3 秒 | 数据量、硬件、并发与模型依赖说明 |
| 成本 | 网页/图片/PDF 页/音频分钟可计量 | 供应商用量与阶段账单；据此设额度 |
| 数据控制 | 撤销、导出、删除与失败清理可观察 | 操作记录、期限配置、恢复演练 |

性能测试建议基线为 10 个用户、每人 1,000 条资料和 5 路并发；这是测试提案，应按真实试点容量调整，并附实际片段数。样本规模有限时，成功率只代表该样本集，不外推为服务保证。

## 4. 风险与处理顺序

| 风险 | 尽早验证 | 不通过时处理 |
| --- | --- | --- |
| iOS 分享扩展生命周期/文件权限 | A02 | 修正原生落盘方案；不以 Web 分享替代并声称完成 |
| MCP 客户端协议或认证不兼容 | A02 | 锁定经过验证的 SDK/认证组合；记录支持范围 |
| 国内平台全文不可得 | A03/C02 | 链接与备注保存，明确待补充，不绕过平台限制 |
| OCR/转写质量与成本不满足 | C02 | 更换适配器或缩小公开支持规格，范围调整须评审 |
| 中文与代码术语召回不足 | A03/C03 | 调整分词词典、切片、召回权重，以同一评测集比较 |
| 离线队列跨账户串传 | B05/C01 | 队列绑定账户，重试前复核，作为发布阻断项 |
| 删除只删主表而残留可读证据 | B04/D01 | 读取先过滤墓碑，资产/版本/索引独立清理并复测 |

## 5. 确认后的首轮行动

先处理 A01～A03：确认终端技术栈、首个 Agent 客户端、部署地区和可用账号/设备；随后冻结 M1 接口与数据库迁移，实施 B01～B04。首轮完成以“可重复运行的权限、采集与证据测试”为标志，不以代码行数或页面数量衡量。

工期在 A02 完成后估算：拆分后端、终端、解析、测试的工作量，按实际可投入人员计算关键路径；供应商开通、签名与真机测试等待时间单列，不混入开发完成率。
