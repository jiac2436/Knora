# A1：知识库视野实施记录

日期：2026-10-09。已实现P0/P1基础及P2有界加工、分批合成和受授权约束的自动调度；P3已接入关键词/节点向量辅助召回及Owner层级导航API，尚未完成虚拟处理中间层导航、客户端入口和真实模型验收，不能作为完整功能交付记录。总体范围及验收按 [实施计划](./A1知识库视野与分层检索实施计划.md)。

## 1. 已落地的共享规则

- `services/api/app/domain_processing.py`：严格的策略、预算、待处理状态、资料依赖和域输入清单模型；独立调度判断，没有网络、文件或数据库写入。
- `services/api/app/domain_inputs.py`：读取当前owner/domain下的依赖清单；App与可分享范围分离，项目/标签过滤后的资料集合可进一步收窄；生成稳定指纹及发布前的依赖一致性检查。
- `services/api/tests/test_domain_processing.py`：40项策略与数据库快照测试，仅使用隔离测试库及模拟网关。

初始策略为关闭、零调用/输入预算。已开启策略的合并等待默认30秒、最长300秒；UTC带时区时间参与计算，显示时区由客户端处理。手动更新可跳过等待/自动暂停，但不能绕过授权或预算。首次构建必须由手动确认开始；已在处理中的任务不再次调度；未知结果必须另行确认才能手动重试。

`dispatch_reason`只返回允许或阻止原因。P1的`domain_runtime.reserve_domain_call`已实现短事务锁、generation检查、预算预留和当前request_id幂等；调用方必须在发送前提交预留，不能跨网络调用保持事务。完整任务/请求历史与检查点仍待实现，不能把当前请求预留当成整个付费流水线已完成。

资料指纹包括标题、正文与实际证据文本/位置、域归属、可见性、覆盖、有效标签及来源、项目绑定、个人上下文、实践记录和当前有效单篇产物。未分析资料也在清单中，摘要ID为空。有效摘要复用现有版本/过期校验，并检查引用确实能解析到原文；不选择任意“最新”产物。阅读位置、上传进度和更新时间不影响输入。

清单只返回依赖ID与哈希，不返回原文、备注、密钥或网关信息。指纹对成员顺序稳定。当前检查要求完整成员一致：新增、移出、删除、撤销共享或输入变动后旧域产物不可复用；空域仅可显示本地目录，不作为AI事实来源。

此函数是内部共享基础，不是MCP授权入口。Agent调用方必须先验证连接状态和域授权，再解析项目/标签等过滤范围；不得直接向Agent返回App范围清单。输入快照未作为公共端点；本地主题App API见第三批记录。

SQLite输入变更登记选择同事务触发器：覆盖Source、Revision、Evidence、上下文、经验、有效标签/标签名、项目绑定、有效单篇产物和人工主题变更。跨域移动登记两域；删除和撤权先阻止当前产物读取，不等待任务。触发器必须进入现有白名单及版本校验，开发/随包模式一致；直接SQL更改也需验证。正式输出写入只登记正式数据变化，不重复触发输入加工。

源码schema已为v10。v8→v9→v10迁移升级前自动快照备份，校验旧触发器后安装新触发器；保留v1～v9恢复支持。输入触发器只登记代次及首个/最近变更时间，不自动调用模型。私有资料的内容修改只更新App范围；撤销共享登记共享范围以使旧结果失效。历史版本的增删可能保守登记dirty，后续任务须核对有效输入指纹后跳过无变化加工。

策略作为domain正式聚合进入本地变更日志、提交快照和可读导出。预算计数、在途request_id与dirty状态属于运行数据，备份中清除。备份中的策略保存配置但关闭启用、暂停并清零授权预算；恢复后需重新确认。当前Worker启动将generating标为unknown，保留已有预留，不自动重发。尚无库级生成任务自动发送路径。

旧macOS运行包仍是v8，不应拿它运行已经升级的v9/v10数据库。此次未升级用户实际数据库或替换App；后续交付须按BUILD重新组装当前后台与完整App，不能仅重新编译Swift。备份归档格式版本仍为1，数据库内部新增v9/v10表；不支持自动数据库降级。

## 4. 第三批：本地主题组织（v10）

本地候选规则：现有正式“主题类”标签覆盖至少两篇当前资料，形成独立主题节点；手工/AI双来源同标签不重复计数，一条资料可属于多个主题。此批只复用标签，不做向量聚类或模型命名，不将候选目录称为AI综述。没有标签或只有单篇命中的资料保留在未归类计数中。

## 5. 第四批：有界节点概览契约与网关

新增`domain_contract.py`、`domain_summary_inputs.py`及`services/worker/domain_summary.py`。网关新增独立`POST /v1/summarize-node`，不复用单篇source_id/kind伪装多篇；原有单篇分析与RAG问答接口保持兼容。源码schema仍为v10，本批不修改持久化格式。

每次最多20个上下文节点、20篇原文资料、80条原文证据；原文每条最多3000字符、总计18000字符，上下文摘要总计6000字符。上下文绑定source/revision及原文引用；源版本混杂、未知引用、无对应摘要的证据和摘要自循环均拒绝。主题输入只接受单篇摘要，域输入契约可接收有原文引用的主题摘要，最终调用原文支撑每个结论。

输出为概览、最多3条独立要点及最多3条限制；所有text合计域最多500字符、主题最多800字符。空白、重复陈述、未知/重复引用拒绝；不预设共识/冲突，不自动打标或更改归属。DeepSeek请求明确关闭thinking，输出2048 token，现有512KiB输入/256KiB响应及网关缓存限制继续生效。

冻结器只读取当前有效单篇摘要及其真实引用片段；未分析、过期、超预算或证据过长的资料记录为未纳入，不自动补做付费分析、不随意截断原文以假装引用完整。覆盖分母保留当前范围全部资料，区分纳入数量与是否完整选择；无论资料数是否全部纳入，都不声称阅读了完整原文。大主题/域超过单次预算时只形成部分输入，后续必须实现多批处理。

目前冻结器是单篇摘要输入的启动路径：可准备主题请求，也可准备一个有界域请求；尚未持久化主题产物并按主题逐层合成域概览。不能把此辅助路径称为完整的分层知识域加工。

`validate_node_publication`校验请求ID、owner/domain/scope、当前原文/摘要/主题/覆盖输入，在本地SQLite短写事务中重核快照。它是发布前置条件，调用方后续必须在同一事务写入不可变产物和发布指针。当前没有实际发布写入。网络调用函数只尝试一次，不持有数据库锁；超时/连接中断/服务器结果未知不自动重试，结构错误返回安全诊断。

网关相同ID/相同输入复用结果或失败任务，相同ID/不同输入返回409；进程重启会清空内存缓存，不能代替本地持久化任务和结果未知保护。尚未注册App收费加工入口，现有Worker主循环未调用此新模型发送函数，默认不会自动产生费用。

## 6. 第五批：单节点持久化执行与发布（v11）

新增 `domain_summary_jobs.py` 及任务/产物专项测试，Worker接入显式排队的概览请求。新增两张表：`domain_summary_jobs` 存冻结输入、授权编号、网关地址、预算预留量、预留时间及执行状态；`domain_summary_artifacts` 存完整输入依赖、模型响应、原文引用和覆盖信息。两者不存访问令牌。任务的输入/预算及正式产物不可原地改写。

### 执行与安全边界

1. 预览只做本地读取，返回内容哈希、纳入/排除范围、一批调用数和保守输入预算。授权与创建任务分离；新请求必须匹配预览哈希。变更后重新预览，未分析资料不被静默补做分析。
2. Owner App API只服务所属知识域；App和shareable单独授权/存储。同范围只能有一个pending/running任务。当前仅支持SQLite。
3. Worker在短事务中重新检查快照、代次、授权及网关地址，预留预算并持久化running，再提交事务后发送HTTP；模型调用不持有SQLite写锁。生成预算按UTF-8字节数加8192提示词/封装余量预留，属于保守授权量，不是供应商账单token数；实测用量随响应保存在产物中。
4. 超时/中断记unknown，失败记failed，不自动重发。启动时running转unknown，保留已预留预算。相同请求编号重提只返回原任务；确认可能重复产生用量后，才允许新编号重试。
5. 输出结构/引用校验及完整输入比对与产物插入在同一短事务内完成。输入已变化记stale，不发布；已消耗预算保留。读取产物也重新检查输入，撤权、删除、改名、移动、主题成员变化后的旧概览不能作为当前知识返回。
6. 域概览当前始终标为partial：它来自有效单篇摘要及被引用的有界原文片段，不能声称读完全部正文。主题完成后不会将整个域标成ready。
7. 产物纳入domain正式变更日志、提交快照、备份及可读导出；不触发输入代次反馈循环。备份清除所有概览任务与运行状态，原有恢复流程关闭AI授权；恢复不会重放收费任务。永久清理原文时联动删除包含它的概览原文片段及任务快照。

### API顺序（客户端界面尚未接入）

全部需要现有Owner App凭证，不能使用Agent只读凭证：

- `POST /v1/domains/{domain_id}/analysis/preview`：`scope`默认app，`topic_id`可选，零模型调用；返回`preview_hash`、`coverage`、`calls=1`及`input_token_reservation`。
- `PUT /v1/domains/{domain_id}/analysis/authorization`：明确新`authorization_id`、`scope`、`policy.enabled/max_calls/max_input_tokens`；预算周期不自动重置。
- `POST /v1/domains/{domain_id}/analysis/jobs`：新`request_id`及上述`preview_hash`，同scope/topic选择；默认不确认未知结果。输入预算不足直接拒绝。
