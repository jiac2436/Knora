# Mac 客户端功能清单

梳理日期：2026-10-19。依据当前正式 App 的 release.json、固定源码记录以及对应界面与调用逻辑。此清单为功能盘点，不代表对每项功能重新执行完整验收。

正式入口：apps/macos/dist/知识收集箱.app。发布依据见 [release.json](../apps/macos/release.json) 和 [发布说明](../apps/macos/RELEASE.md)。

## 1. 运行与本地数据

- 原生 macOS 客户端；当前随包交付面向 Apple Silicon。
- 完整包内置 Python、API、Worker 及本地模型资源；打开 App 自动启动本机服务，退出后停止，无需手动启动数据库、Docker 或独立 API/Worker。
- 日常本地模式直接打开知识库，不需要邮箱或密码。
- 资料、原件、版本、分析和问答记录保存在本机。
- 本地服务启动可取消；异常退出后有受限次数的自动恢复，支持手动重试。
- 外置后台开发模式仍有邮箱密码注册、验证、登录、找回密码、Token 连接及开发邮箱会话恢复。它们不是当前完整本地版的日常入口；邮件流程依赖后台邮件配置。

界面中可切换的“知识库”主要对应同一本地数据库内的知识域；备份恢复操作针对整个本地数据集，不是仅当前知识域。

## 2. 内容采集

- 内容分为文件、链接、笔记。
- 粘贴文本、HTTP(S) 网址或 Finder 文件；也可通过文件选择器多选添加。
- 单独网址识别为链接；混合文字及网址按笔记保存。
- 笔记标题统一为“笔记”，侧栏展示正文预览；文件标题使用文件名；链接初始使用网址，读取成功后使用网页标题。
- 采集时选择目标知识域，可关联项目；支持创建知识域和项目。
- 添加至待发送列表，显示上传、识别、保存和失败状态；支持移除、重试和手动刷新。
- 本地版保存草稿、待发送队列及暂存文件，重启后恢复；恢复不自动重发。
- 单文件上限 50 MB；⌘↩ 发送。
- 文件类型包括 PDF、Markdown、Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV，具体解析质量取决于文档格式和解析器。

## 3. 网页、微信及飞书读取

- 普通公开网页异步读取标题与正文，显示读取状态，结果持久化为资料版本、证据及检索数据。
- 支持轻量读取和 Crawl4AI 浏览器读取选项、通用正文清洗；浏览器读取依赖相应服务环境。
- 阅读器可查看 Markdown、重新读取成功网页；失败可重试并保留原网址。
- 自动识别微信公众号文章，使用专用读取路径提取正文、标题及可用元数据；不需要绑定微信账号。
- 微信图片独立归档，在正文原位置展示；可放大看原图、补齐旧文章图片及重试失败图片。
- 飞书通过配置好的 CLI 和用户授权读取文档，支持图文保存、图片查看及可用 OCR 文字展示。
- 设置中可检查飞书连接、补充授权、断开连接；网页网络设置提供 IPv4/IPv6 Fake-IP 代理兼容选项。

不承诺绕过登录、付费、验证码、下架或反爬限制；微信公众号读取不等于订阅号同步。普通网页也不等于完整网站镜像、音视频下载或任意附件抓取。

## 4. PDF 与文档解析

- 数字 PDF 直接提取文字；扫描页面可使用本地 PaddleOCR。
- 提供 PDFium + PaddleOCR、pdf-inspector + PaddleOCR 引擎选项。
- 当前随包本地版使用随包 Small OCR 模型；开发后台模式另有 Tiny/Medium 选项。
- PDF 自动排队解析，可从阅读器重新扫描。
- Markdown 读取 UTF-8 内容；其他支持的办公文档通过本地解析流程转换为可检索文字。
- 普通文档解析失败可使用已保存原件重试，不必重新上传。
- 已提取文字按页或段落形成证据，并参与检索。

PDF 正文 OCR 不等于已归档或理解 PDF 内所有图片、图表、公式和版面。

## 5. 浏览、阅读与编辑

- 左侧按标题、录入日期、内容标签浏览；标题列表可分页加载。
- 底部显示当前知识库，可快速切换知识域、查看全部资料及按项目筛选。
- Markdown 风格阅读器展示标题、段落、列表、表格、代码等结构，支持字号调整。
- 支持阅读／编辑模式切换，提供粗体、斜体、标题、引用、提示框、链接、表格、待办与代码块插入。
- 正文编辑保存为新版本，可放弃未保存修改。
- PDF 使用 macOS PDFKit 原件阅读，纵向连续滚动、页码导航，并可切换提取文字视图。
- 图片可按原文顺序查看，并打开原图。
- 右侧“证据与笔记”默认收起，可手动展开；窄窗口采用面板方式。
- 正文、补充、版本和已读证据有运行期缓存；重复打开优先使用缓存。
- 发现服务端版本更新时显示绿色空心圆点，点击圆点主动获取新内容。
- PDF 下载、解析及阅读视图有运行期缓存，切回同一 PDF 可复用位置；并非无限缓存或永久离线缓存。

## 6. 搜索与定位

- 放大镜或 ⌘F 打开顶部浮动搜索。
- Tab 切换全局搜索／当前内容搜索；停止输入约 0.5 秒后执行。
- 上下键选择、回车或鼠标打开；Esc 关闭并清空输入。
- 全局检索通过本地后台查询索引，结合关键词与语义召回，不局限于客户端已打开的缓存。
- 当前内容搜索针对当前阅读内容定位。
- 全局结果打开后定位相应原文证据，字面匹配时可高亮；语义匹配未必包含相同字词。
- 支持用正式标签名或别名筛选，支持总结索引与本地索引重建。
- PDF 可定位至文字证据或相应原件页码。

语义相关性不保证每次符合用户意图；索引未完成、文本尚未解析或召回阈值均影响结果。搜索命中不等于事实正确，需核对原文。

## 7. 版本与证据

- 查看资料历史版本及相应证据。
- 添加个人补充并保存为新版本。
- 搜索、AI 分析、知识域概览和问答可引用具体证据。
- 支持从引用跳转文章、段落、PDF 页或对应原图。
- 原资料变化、删除或移出范围后，相关产物／引用可标记过期。
- 证据与版本用于追溯，不代表模型结论已经自动核实。

## 8. 标签管理

- 支持关键词规则生成的基础自动标签，以及分析生成的 AI 标签。
- 人工添加和移除资料标签；AI 与人工来源分别记录。
- 标准目录包含主题、内容类型、涉及对象三个维度。
- 主题标签支持两级；可编辑名称和层级。
- 添加／移除别名、合并标签。
- 用标签浏览、筛选及辅助检索。

规则标签覆盖有限；AI 标签需要模型分析。主题分类目录与标签目录是相关但独立的管理入口。

## 9. 单篇 AI 分析

- 手动预览分析范围与调用数，确认后执行。
- 生成简短概览、总结、洞察、标签及相关分析结果，持久化到本机。
- 支持长文本有界分段及合成，界面显示范围和覆盖限制。
- 对已归档且符合条件的图片支持图文联合分析、长图分块，分析引用可回到原图。
- 查看分析任务进度、历史结果、错误与过期状态，可重新分析。
- 浏览或刷新不会自动重做单篇付费分析；结果未知时不自动重发。

需要配置可用的文字模型，图片分析还要求兼容视觉模型和已保存原图。部分历史分析使用纯文字输入，不会因升级自动补成图文结果。

## 10. 知识域组织与加工

- 创建、切换知识域和项目；管理知识库。
- 删除知识库时连同库内资料移入回收站；可恢复。
- “知识库概览”包含概览、主题分类、知识域信息三个页面。
- 概览展示整体理解、原文引用、加工覆盖与未纳入资料。
- 主题支持两级目录、手动创建／编辑及资料多主题归属，能展开查看原文。
- 信息页展示资料分析状态、分类与标签、本地已统计数据量及多层检索索引准备情况。
- 支持生成／更新概览、查看更新记录与加工中间结果、重建本地概览索引。
- 全量分析先预览可复用及待分析资料，再确认执行；可查看进度和停止后续步骤。
- 内容变更后的自动概览更新需要显式授权，可设置资料／步骤／调用及输入 token 预算，支持暂停／恢复。

这里的树形组织与主题关联不等于 Obsidian 风格的可视化知识图谱。

## 11. 知识库问答

- 可对知识库、知识域或主题范围提问，主题范围包含子分类。
- 本地检索原文，再将问题和选中的证据发送给配置模型回答。
- 支持标签筛选、本地会话切换和问答历史保存。
- 回答展示来源引用，可跳转原文；资料不足、失败及引用过期有相应状态。
- 每次问题独立检索，历史回答不作为新的事实证据。

当前问答以文本证据为主，不能视为可直接查询所有原始图片、音频和视频的完整多模态 RAG。

## 12. 模型与 AI 配置

- 设置中直接填写模型 API 基础地址、API Key、文字模型及可选图片模型，无需单独启动网关。
- 支持 DeepSeek 适配和 OpenAI 兼容 Chat Completions 接口；兼容服务需满足现有 JSON 输出契约。
- 保存并应用后自动重启本地服务；可移除模型配置。
- API Key 放钥匙串，普通配置按本地数据集保存，界面不回显密钥。
- 保留独立外部 AI 网关地址及凭证配置。
- 本配置不管理 OCR 或本地 Embedding 模型；二者与生成式模型独立。

保存只验证配置格式，不代表实际厂商连接、余额、权限或结果质量通过。Responses、Claude Messages 等专有协议不在当前直接适配范围。

## 13. Agent 接入

- 为每个 Agent 建立独立只读连接，授权可访问的知识域。
- 可复制 MCP 配置、检查连接、断开配置、撤销访问凭证并查看到期状态。
- Codex 可生成／更新知识库插件；支持完成接入和启用插件。
- Claude Code 提供接入及自动参考知识库规则配置；Workbuddy 主要采用高级手动配置。
- 外部 Agent 可通过授权工具检索、列目录、读取证据及相关知识产物。
- 支持文章引用导航链接，回到 Mac 客户端查看原文。

需保持 App 运行。规则或 Skill 并不保证宿主在每一轮都调用知识库；需要宿主安装／重新加载相应连接。

## 14. 数据维护

- 右键标题删除资料，本地版先移入回收站。
- 回收站可分页查看、恢复及确认永久删除资料；知识库删除亦有恢复入口。
- 导出本地备份，包含入库资料、版本、补充和文件原件／已归档图片。
- 从备份恢复到新本地数据集，可回到恢复前数据集。
- 可读导出为 Markdown 与原件 ZIP，供外部使用；它不等同于可恢复备份。
- 备份不包含模型密钥、登录凭证、运行期缓存、草稿或未发送队列；备份未加密。

## 15. 当前没有完整交付的能力

- 多设备云同步、团队协作与共享编辑。
- Obsidian 风格可交互知识图谱、通用人工双向链接工作流。
- 微信订阅列表拉取、自动同步公众号历史文章。
- 系统各应用通用右键采集入口／微信小程序分享入口。
- 任意站点的无条件读取、音视频转写及完整多模态检索问答。
- 面向所有 Mac 的正式发行保障：当前本地签名，Developer ID、公证、完整跨架构与清洁机器验收仍有边界。

当前主流程已覆盖采集、保存、解析、阅读编辑、检索、AI 加工、证据追溯及只读 Agent 使用；以上边界需与功能存在性分别评估。
