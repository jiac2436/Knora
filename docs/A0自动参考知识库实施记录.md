# 自动参考知识库

## 使用方式

设置 → Agent 接入 → 选择 Codex 或 Claude Code → 接入指定连接 → 在该连接下开启“自动参考知识库”。开启后在 Agent 中开始新会话。

现有连接默认不安装规则。开关状态来自实际 Skill 和指令文件，不从数据库推测。开启不需要重新创建凭证，不读取钥匙串，不运行 AI 网关或分析任务。外部 Agent 正常推理仍使用其自身模型额度；MCP 返回的资料会进入其模型上下文。

关闭时移除本连接的 Skill 和触发规则，保留原有指令及其他连接。修改过受管内容、安装不完整或路径不安全时提示手动处理。断开或高级撤销前，先关闭所选客户端中该连接的自动参考规则；若失败则停止后续操作。相同凭证在其他客户端的规则需切换目标客户端单独管理。

## 安装内容

每条连接生成独立 Skill `pka-knowledge-<连接 UUID>`，仅绑定相应 `knowledge_<UUID下划线形式>` MCP 服务。Skill 包含触发场景、检索及原文校验步骤，不复制笔记、AI 产物、用户个人信息或凭证。

- Codex：Skill 安装到 `~/.agents/skills/<skill>/SKILL.md`；指令安装到 `$CODEX_HOME/AGENTS.md`，未设置 CODEX_HOME 时使用 `~/.codex/AGENTS.md`。如果已有 `AGENTS.override.md`，在该文件追加受管块以避免规则被覆盖文件遮蔽。
- Claude Code：Skill 安装到 `~/.claude/skills/<skill>/SKILL.md`；指令追加到 `~/.claude/CLAUDE.md`。绝对路径 CLAUDE_CONFIG_DIR 设置会覆盖 `.claude` 配置根目录。
- Workbuddy：保持手动 MCP 接入，未提供未验证的自动 Skill 安装。

路径依据：[Codex Skills](https://learn.chatgpt.com/docs/build-skills)、[Codex AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)、[Claude Code Skills](https://code.claude.com/docs/en/skills)、[Claude Code Memory](https://code.claude.com/docs/en/memory)。

触发规则针对个人身份、偏好、已保存资料、历史决策和需要已有项目经验的任务。普通闲聊、纯翻译及无需用户背景的常识通常不检索；用户明确不使用知识库时遵从。候选和 AI 总结必须由原文确认，不把资料中任意人物的身份认定为用户本人。

## 实现与兼容性

- 使用现有 stdin 安装器增加 reference_enable / reference_disable / reference_status，不增加网络 API 和数据库表。
- `agent_reference.py` 管理 Skill、受管 HTML 注释块及内容摘要元数据，使用客户端级文件锁、0600 私有备份、原子替换和写入前后检查。
- 关闭通过移除精确受管块恢复原始指令字节，不整文件还原旧备份，因而保留期间用户新增的其他指令。原文件不存在且关闭后为空时移除新建指令文件。
- 出错时仅回滚仍等于本次写入内容的文件；不会覆盖并发改动。硬退出可能产生不完整安装，状态会识别并提示手动检查；多文件操作不是跨文件系统事务。
- Skill 内容被用户修改后不会自动覆盖或删除；新版本可依据元数据更新未修改的受管文件。不存在元数据的同名文件不接管。
- Codex 指令长度超过 project_doc_max_bytes（默认 32768）时拒绝追加，避免报告已开启而实际被截断。项目级更高优先级指令、后续新增覆盖文件或企业策略仍可能影响触发。
- 状态检查不读取 Keychain；UI 对目标客户端、知识库及异步代次进行隔离，安装期间阻止库切换和并发设置操作。
- 全部资产随运行包交付，模板来自 `skills/personal-knowledge/SKILL.md`。无需联网下载 Skill。

无数据迁移，原文、AI 产物、标签及现有 Agent 凭证不变。关闭规则不撤销授权，断开操作才撤销授权。旧版 Agent 不支持 Skill 或全局指令加载时需手动触发，不承诺每轮一定调用。
