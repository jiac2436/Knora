# L2 客户端服务集成记录

日期：2026-10-01。状态：本地服务启动链路与测试应用已实现，完整 L2 验收仍在推进。

用户本轮明确：不需要迁移旧数据。客户端从正式用户目录的新本地库开始，不导入源码目录中的开发数据库。原有导入工具保留为可选工程工具，不进入客户端启动流程。

## 本轮实现

- 新增 `LocalService.swift`：使用独立的 Keychain 服务项保管 256 位随机本地凭证，经标准输入交给包内 Python，不放入参数、环境变量或偏好设置。
- 包内 Python 使用 `-I -B` 隔离启动，路径来自应用资源目录。数据、缓存、日志显式落到用户 Library 目录；不依赖终端 PATH、开发 Python 或 Docker。
- 新增本地宿主 `app/local_host.py`：初始化正式本地身份和库；在 `127.0.0.1` 上绑定系统分配的空闲端口并保留该 socket，避免探测端口后再绑定的竞争。
- API 完成启动、Worker 通过专用文件描述符报告初始化完成后，才向客户端发送就绪地址。Worker 启动路径与参数隔离，不把代码路径交给业务参数解析器。
- 同一数据目录持有独占实例锁，重复客户端启动不会轮换正在使用的凭证。API、Worker 继续持有共享数据锁，初始化与迁移使用独占数据锁。
- 管道 EOF 表示客户端结束，宿主关闭 API 并停止其创建的 Worker；正常退出同样发送关闭信号。不会扫描、终止系统中其他 Python 进程。宿主运行期间监测 Worker，Worker 异常退出使本地服务停止。
- 客户端随包有运行环境时直接打开本地库，绕过邮箱、密码及开发会话。失败页显示原因并允许重试；本地模式不显示账号退出操作。已有账号/开发连接流程用于未随包的开发构建。
- PDF OCR 显式使用随包 Small 模型；缺失模型时报错，不触发自动下载。客户端本地模式仅提供随包模型选项。语义模型同样指定随包目录。
- 构建脚本接收明确的运行包目录和外部可信 manifest 摘要，校验成功后复制到 `.app/Contents/Resources/runtime`；普通开发构建清除遗留随包资源，避免误用旧后端。

## 构建及验证

```sh
PKA_RUNTIME_PAYLOAD=/绝对路径/已验证运行包 \
PKA_RUNTIME_MANIFEST_SHA256=<可信manifest摘要> \
bash apps/macos/scripts/build.sh
```

运行包按 L0 固定输入重新构建，不能复制开发虚拟环境。Swift 集成验证入口为 `apps/macos/scripts/LocalServiceTest.swift`，编译时同时包含 `API.swift`、`TokenStore.swift`、`LocalService.swift`，执行时传入运行包路径。

源码布局下的宿主测试显式设置 `PKA_WORKER_ROOT` 为仓库根目录；随包客户端不设置该变量，API 和 Worker 均只从包内 `backend` 加载。
