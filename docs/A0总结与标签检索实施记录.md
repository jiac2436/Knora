# A0 总结与标准标签检索实施记录

日期：2026-10-03。状态：第三批工程闭环已实现，真实检索质量评测和 Skill/RAG 完整接入待后续。

## 已实现

- SearchRequest 新增 tag_ids（最多 50）和 tag_query（标准名称/别名规范化精确匹配）。标签集合按任意匹配；未知名称返回空结果，外 owner 标签或 Agent 不可访问标签 ID 返回不存在，不泄露目录。
- 默认筛选只使用人工关联及当前正文版本的已确认 AI 关联，排除未确认候选、拒绝和过期 AI 关联；历史规则标签不参与正式筛选。
- 复用原文检索，增加总结关键词/本地向量和标准标签名称/别名召回，五个通道按 RRF 融合。查询向量只计算一次，复用现有 BGE 模型，未新增云端 AI 请求。
- 所有通道在召回与限额之前应用 owner、领域授权、项目、标签、app_only 与删除过滤。异常索引中跨资料的总结/原文向量关联在 SQL 中排除。
- 总结索引选择最新有效 single/synthesis 产物，排除 segment、旧正文、上下文过期或契约无效的记录。总结引用逐个校验属于当前资料和正文版本，冻结文字必须与原文范围匹配；虚拟切片通过 original_evidence_id 映射回真实证据。
- SearchResult 新增 match_sources、summary_artifact_id、summary_snippet、summary_coverage、正式 tags。原 snippet、evidence_id 和 locator 始终指向真实原文；总结只辅助找文档，不能当成原文证据。
- Mac 全局检索增加标签筛选、命中来源及独立总结片段、索引状态和本地重建按钮。文内搜索不应用标签筛选。旧响应字段缺失时保持兼容。
- 现有 HTTP MCP 和原生 MCP search_knowledge 同步接入标签过滤和总结召回，沿用连接授权和审计；尚未实现新的总结读取工具、完整 Skill 或客户端 RAG 问答。

## 索引与恢复

schema 6 → 7 新增 summary_index_jobs、summary_search_terms、summary_embeddings；不改写知识。派生表不进入知识变更日志/固定提交，恢复包清空派生数据，知识产物继续保留，Worker 恢复后本地重新索引。

关键词先保存，本地向量模型失败仍可关键词检索，任务记录安全错误类别。失败需手动重建，缺失索引自动补排，running 任务重启可回 pending；这些都是本地计算，不消费大模型用量。删除、编辑或新总结到来期间，发布前重验来源/目标，不能用旧向量覆盖新状态。永久删除先清理索引外键子表，再删除产物。

新增 GET /v1/summary-index 状态、POST /v1/summary-index/rebuild（可选 source_id）；仅 App owner 可访问。Agent 不提供未过滤的索引统计。支持旧 schema 1～6 恢复包升级；升级前备份，旧客户端不能打开 schema 7。

## 当前边界

总结有效性继续使用正文和完整个人上下文快照校验。应用分类/项目建议或改变个人上下文后，同批总结会过期并退出默认检索；原文和当前有效正式标签继续可查。若将来区分“正文总结有效性”与“归类建议有效性”，需另行调整版本语义和测试。

未宣称真实模型事实准确率或检索召回率，仍需中英文/PDF/网页样本对照评测。派生索引采用既有本地模型和扫描式向量排序，本批未引入新的向量数据库或大规模性能方案。
