# M1 接口契约

状态：开发冻结版。所有接口使用 `/v1` 前缀；开发环境通过 `Authorization: Bearer <token>` 解析账户。写入采集接口必须提供 `Idempotency-Key`。

## 采集

`POST /v1/captures`

```json
{
  "capture_type": "text | url | browser_page | browser_selection",
  "title": "可选标题",
  "source_url": "可选来源 URL",
  "captured_at": "可选 ISO 8601 时间",
  "content": {
    "text": "保存的正文或片段",
    "image_urls": []
  },
  "coverage": "full_text | partial_text | link_only",
  "context": {
    "domain_id": "知识域 ID",
    "project_id": "可选项目 ID",
    "note": "可选个人备注",
    "save_reason": "可选收藏原因"
  },
  "client": {
    "kind": "mobile | browser_extension",
    "version": "客户端版本"
  }
}
```

服务端必须复核知识域和项目属于当前账户；客户端提交的 ID 不构成授权。相同账户、相同幂等键和相同请求返回第一次结果；相同幂等键但不同请求返回 409。

## 列表与详情

- `GET /v1/me` → `{ "id": "稳定账户 ID", "display_name": "可选显示名" }`；用于设备队列绑定账户，身份只能由凭证解析。
- `GET /v1/domains` → `{ "items": [{ "id", "name" }] }`
- `GET /v1/projects` → `{ "items": [{ "id", "name" }] }`
- `GET /v1/sources` → `{ "items": [...] }`
- `GET /v1/sources/{source_id}` → 当前版本、证据、个人上下文及经验记录

## 个人上下文与实践记录

- `PATCH /v1/sources/{source_id}/context`：可更新知识域、项目、备注、收藏原因、适用条件和可见性。移动到新域后立即使用新权限。
- `POST /v1/sources/{source_id}/experiences`：追加 `untried | effective | partially_effective | ineffective` 及用户说明，不覆盖历史记录。

## 检索与 Agent

- `POST /v1/search`：查询当前账户资料；可用项目和知识域缩小范围。
- `POST /v1/agent-connections`：创建连接并授权知识域。
- `DELETE /v1/agent-connections/{connection_id}`：立即撤销后续访问。
- `search_knowledge`、`get_evidence`、`get_source`：三个只读 Agent 工具，每次调用都复核连接、域授权、资料可见性和删除状态。

## 错误

错误体统一包含 `code`、`message`、`request_id` 和 `retryable`。未认证返回 401；无权访问与不存在统一返回 404；幂等或并发版本冲突返回 409；超限返回 429。
