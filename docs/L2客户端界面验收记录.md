# L2 客户端界面验收记录

日期：2026-10-01。范围：本地文字采集、设置展示和正常退出/重启的图形界面冒烟。

## 测试隔离

新增 `apps/macos/scripts/LocalUITestApp.swift` 和 `build_ui_test.sh`。测试应用复用正式 `WorkspaceView`、`CaptureModel` 和 `LocalService`，通过已有依赖注入传入临时 home、队列和运行包。每次构建生成独立应用标识及同名 Keychain 服务；应用从自身 Info.plist 读取配置，重新打开仍使用同一份测试库。

入口要求测试根位于系统临时目录且名称以 `pka-ui-test.` 开头，应用标识以 `local.pka.ui-test.` 开头。测试运行包通过显式参数指定，不复制、不修改已有运行包。正式客户端、真实知识库和旧开发库均未操作。

本轮使用 `/tmp/pka-l2-runtime-v4`，清单摘要为 `735d2d0f85c061265661d8639fc1c4a48b60dff91daf41ec650f76a130bf3d56`。界面动作由 computer-use 技能的 Sky 执行，截图和可访问性文本保存于 [验证目录](./verification/l2/ui-smoke.json)。

## 实测结果

| 场景 | 结果 |
| --- | --- |
| 全新本地库启动 | 自动打开本地阅读器，无需登录 |
| 创建知识域 | 创建成功并选中，退出后保持 |
| 输入笔记并加入列表 | 识别为笔记，显示待发送 |
| 另留一条未入队草稿后退出 | 草稿和一个待发送条目落盘；资料数为 0 |
| 第一次重新打开 | 草稿、知识域和待发送条目恢复；数据库仍为 0，未自动发送 |
| 手动点击保存 | 草稿同时加入列表，两条均显示已保存，数据库恰好为 2 |
| 阅读器 | 知识树显示两条，选择后正文与输入一致 |
| 本地账户设置 | 展示无需登录、关闭客户端后服务停止；未提供开发 Token 复制入口 |
| 本地 OCR 模型菜单 | 默认 Small，展开仅出现随包 Small 模型 |
| 第二次重新打开 | 资料树、正文和两个已保存队列条目恢复，发送按钮禁用 |
| 正常退出 | 实例锁和服务锁均可重新取得排他锁；SQLite 完整性检查为 `ok` |

已查看采集页与阅读器截图，本轮没有发现阻断上述路径的布局问题。正式 Sources、数据库结构和持久化格式没有因本轮验收改动。

## 复验入口

```bash
bash apps/macos/scripts/build_ui_test.sh /绝对路径/已验证的运行包
```

脚本输出临时 `.app` 路径。打开该测试应用后，使用合成文字测试；不要打开正式客户端代替该入口。构建脚本仅检查 Python 存在，运行包完整性应先通过既有 `verify_runtime.py` 检查。

退出测试应用后，可读取其 `Contents/Info.plist` 中的 `PKATestRoot` 和 `CFBundleIdentifier`，确认服务锁释放，再清理该测试 Keychain 条目与临时目录。删除凭证时必须使用测试应用的完整标识，不能使用正式客户端的服务名。本轮已退出测试应用、删除独立测试凭证，并清理临时应用和数据。

## 验证边界

这是单台当前 Mac 的正常启动/退出界面冒烟，不代表 L2 全部完成。未验收文件选择/拖放/上传的图形路径、图形界面的删除操作、实际设备休眠、物理满盘、后台写入满盘及长时间负载。先前 CSV 上传与恢复的模型/服务集成测试仍是这些底层路径的已有证据，不能代替图形验收。签名验证仅为临时签名，不代表发行签名、公证或清洁设备安装通过。
