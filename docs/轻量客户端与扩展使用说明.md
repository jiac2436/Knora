# 轻量客户端与扩展

基础 App 已包含本地知识库、必要运行环境和云端 AI 调用代码，不需要用户安装 Python、Docker 或手动启动后台。未安装扩展时，仍可保存原文件、阅读已有正文及使用精确搜索。

## 按需安装

打开“设置 → 扩展功能”，选择需要的能力并点击“安装”：

| 扩展 | 用途 |
| --- | --- |
| 语义搜索 | 在本机按含义检索原文、摘要，为知识库 AI 问答提供检索能力 |
| 文字识别 | 在本机识别扫描版 PDF 的文字 |
| 文档解析 | 解析 Office 文件和复杂 PDF 版面 |

下载清单展示组件、版本、大小和进度，只需点击一次安装，无需逐项操作。三项能力均保留离线扩展包导入。具体大小和组件数量以当前 App 的固定清单为准，在线下载量可能与离线压缩包不同。

下载期间可以继续使用客户端。**安装、启用、停用或卸载后，等待当前任务结束，用 ⌘Q 正常退出并重新打开，变更才会生效。** 页面会区分当前生效状态与等待重启状态，不会强制中断资料处理。

TXT、Markdown 和基础数字 PDF 文字提取不要求 OCR 或文档解析扩展。复杂扫描 PDF 的高级解析可能同时需要这两项能力。缺少能力时保留原件，并提示安装或明确重试，不把半成品当作解析成功。

## 下载与校验

下载源已内置。Python 依赖使用清华与阿里镜像，向量模型使用固定的魔搭来源，OCR 模型使用 Paddle 官方来源，Mac 原生运行组件使用固定 Homebrew 镜像制品。

客户端按随 App 固定的版本、长度、SHA-256 和文件清单校验，安装前以合成数据检查引擎。不在线执行 pip 依赖解析，不编译源码，也不要求系统 Python、Homebrew 或 Xcode。取消、校验或自检失败时不启用半成品，不擅自切换未经验证的新版本。当前不支持断点续传。

## 升级、停用与已有资料

0.2.0 配套扩展使用 **1.1.0 / CPython 3.12**；旧 1.0.0 / CPython 3.10 的二进制扩展不能混用，需要安装新版配套扩展。旧资料和已保存分析不会因此删除。

停用保留程序文件；卸载移除扩展程序及专属模型，仍被使用时等待正常退出后完成。原文、图片、历史版本、AI 分析、标签、概览和问答记录继续保留。执行新的语义检索、扫描识别或复杂解析时需要对应能力；云端单篇分析和知识库更新不强制要求语义搜索扩展。

扩展保存在当前用户的应用支持目录，不修改基础 App 内部文件。开发者请按[当前构建流程](../apps/macos/BUILD.md)生成基础包、配套扩展和下载清单，不复用历史验收目录或个人已安装的扩展。
