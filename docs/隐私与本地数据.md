# 隐私与本地数据

Knora 默认在当前 Mac 保存知识库、原件、图片、分析结果、索引与阅读位置，基础客户端不要求注册或登录。删除 App 本身不会自动删除这些本地资料。

## 什么时候会联网

- 采集网页、下载原文图片或读取飞书内容时，会访问相应来源；飞书可能使用用户自行配置的本机 CLI 授权。
- 在设置中安装扩展时，会从内置的公共依赖镜像及模型来源下载固定文件，并校验大小和 SHA-256。下载请求会向来源站点暴露正常连接信息，例如 IP 地址。
- 使用 AI 分析、知识库更新或问答时，会把相应正文、已选图片及必要上下文发送给用户配置的模型服务。界面要求确认分析操作；服务商的数据政策由用户选用的服务决定。
- 连接浏览器插件或 Agent 后，本机服务按凭证及已授权知识库范围提供访问。Agent 接入目前为只读；新建知识库不会自动加入已有授权范围。

项目没有接入产品遥测或崩溃上报 SDK。外部模型、网页及第三方 CLI 的行为不由 Knora 控制。

## 密钥、备份与分享

直连模型 API Key 保存在当前用户的私有配置文件，目录权限为 `0700`、文件权限为 `0600`。这是文件访问隔离，不是加密保险箱；拥有当前用户权限的软件可能读取它。旧钥匙串仅进行无交互兼容迁移，失败时需要重新填写。

知识库备份不包含模型 API Key。备份和可读导出仍可能包含正文、图片、分析及其他私人资料，分享前应检查。回收站内容在彻底删除前仍占用存储。

默认数据与状态目录延续内部应用标识，位于 `~/Library/Application Support/` 下的 `local.pka.knowledge-inbox` 与 `local.pka.knowledge-inbox-state`；切换或恢复多个本地资料库时还会使用 `local.pka.knowledge-inbox-libraries`。排查问题时请优先使用合成数据，不要公开整个目录、数据库、日志或配置文件。
