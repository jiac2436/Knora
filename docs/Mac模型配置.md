# Mac 模型配置

入口：设置 → 模型与 AI → 直接配置模型。

填写接口类型、HTTPS API 基础地址、文字模型名称和 API Key；图片分析可单独指定视觉模型。兼容接口通常填写 `https://服务地址/v1`，不要填写完整的 `/chat/completions` 地址。DeepSeek 使用专用适配，其他服务使用 OpenAI 兼容 Chat Completions 协议；模型需支持当前任务要求的 JSON 输出和图片输入。

点击“保存并应用”后，客户端等待当前任务及检查点安全结束，再重启本地服务应用配置。保存只验证配置格式，不调用模型，也不能证明余额、权限或输出质量正常。普通使用无需单独启动 API、Worker 或 AI 网关。

## API Key 的保存

API Key 保存在当前 macOS 用户的私有配置文件，目录权限为 `0700`，文件权限为 `0600`；界面不回显，不写入知识库数据库或导出的备份。文件访问隔离不等于加密，拥有当前用户权限的软件可能读取它。详见[隐私说明](隐私与本地数据.md)。

旧钥匙串值只在禁止交互的条件下尝试兼容迁移，不再为保存新的模型 API Key 请求钥匙串授权。无法静默取得旧值时，需要在设置中重新填写。

修改模型名称时通常可以留空密钥以保持原值；更换厂商或 API 地址时必须重新填写，避免把旧密钥发往其他服务。移除模型配置会停用连接。缺少可用配置时，收集、阅读和精确搜索仍可使用；新的 AI 分析需要先完成配置并确认。

## 分析与兼容

正文、已选图片及必要上下文会发送给所配置的模型服务，可能产生服务商费用。查看已保存的分析结果不需要重新调用模型；“重新分析”仍需确认。

直接模式复用内置模型执行器，不监听额外网关端口。外部网关模式仍保留，只有明确选择时才使用；改换配置不会把旧配置下待处理请求自动转发给新服务。

这里的配置用于云端 AI，不管理本地语义模型或 OCR。可选能力在[扩展功能](轻量客户端与扩展使用说明.md)中安装。当前接口不包含 Responses 或 Claude Messages 专用协议。
