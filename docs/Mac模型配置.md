# Mac 模型配置

入口：设置 → 模型与 AI → 直接配置模型。

填写接口类型、HTTPS API 基础地址、文字模型名称、API Key；图片分析可单独指定视觉模型。基础地址会追加 `/chat/completions`，例如兼容接口通常填写 `https://服务地址/v1`，不要填写完整的 `/chat/completions` 地址。DeepSeek 沿用现有专用适配，其他服务使用 OpenAI 兼容 Chat Completions 协议，要求支持 JSON 输出。

点击“保存并应用”时，内核先检查并等待当前任务及检查点安全结束，再重启本地服务应用配置；不会强行改送在途请求。无需另外启动API、Worker或AI网关。保存仅验证配置格式，不会发送模型请求，不证明服务余额、模型权限或输出质量正常；实际分析仍需模型服务可用。

API Key 保存在本机钥匙串，界面不会回显。一般修改模型名称可以留空保持密钥；更换厂商或 API 地址必须重新填写，以免把旧密钥发给另一个服务。模型名称等普通配置按物理知识库隔离保存在设备偏好中；API Key不写入普通配置、知识库数据库或备份，只通过私有管道交给模型Worker。移除模型配置会停用模型连接，不会悄悄切回旧外部网关。没有Key或钥匙串暂不可用时，阅读、编辑、本地检索和备份仍可使用。

原“外部 AI 网关”模式保留，保存后显式切换。直接模式复用已有分析、知识库问答、知识域总结与引用校验协议，通过进程内传输执行内置网关，不监听额外端口。配置指纹用于任务绑定；改换模型或服务地址后，旧配置下待处理任务不会转发给新模型。

这不是本地模型下载配置，不影响 Embedding 或 OCR。厂商特有的 Responses、Claude Messages 等协议不在本次支持范围；兼容服务的图片输入与 JSON 格式支持需由对应服务提供。
