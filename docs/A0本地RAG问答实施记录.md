# A0 本地 RAG 问答

日期：2026-10-03。首版范围：客户端提问、原文检索、一次网关回答、原文引用和本地会话保存。

## 主流程

Mac 阅读器新增“知识库问答”，支持选择/创建本地会话、正式标签名或别名筛选、手动刷新任务和打开原文依据。发送前明确确认问题与检索到的原文将发给配置的网关并可能消耗额度。历史会话本地保存，每次问题独立检索，不把前一轮模型回答当作事实，也暂不自动解析“它/上述”等跨轮指代。

检索复用原文、有效总结和正式标签的混合召回，但模型输入只含真实原文、资料标题和原文位置。个人备注、总结内容及标签目录不进入回答请求。最多召回 12 个文档结果，每条原文最多 3,000 字符，总计最多 18,000 字符；按实际命中的原文片段取附近节选，排除重复证据和旧版本。问题最多 2,000 字符，其中前 1,000 用作检索查询。本版未增加 reranker 或多轮查询改写。

没有可用原文时本地直接返回“证据不足”，不创建付费任务。其余任务进入 Worker，经新 POST /v1/answer 网关调用一次模型；结构、请求编号、所有引用 ID 都通过校验后保存回答、用量和模型/提示版本。回答仅代表本次检索节选，不能当作全文或整库结论；结构/引用 ID 校验不等于事实正确性验证。来源改变时历史引用标为过期并禁用原文跳转，不能冒充当前知识。

## API 与任务边界

App owner API：GET /v1/rag/config、GET/POST /v1/rag/sessions、GET /v1/rag/turns?session_id=…、POST /v1/rag/turns、DELETE /v1/rag/sessions/{id}。提交必须 confirm_send=true 和 UUID Idempotency-Key；相同请求标识、同一问题返回原任务，参数改变返回冲突。会话同一时间仅一个 pending/running 请求。界面提交失败保留相同会话/问题/筛选的请求标识，不自动重新付费调用；本版删除会话入口仅 API 提供。

问题发送前及结果发布前核验资料 owner、删除状态、当前正文和真实证据归属。冻结后正文变更则取消发送；调用期间变更/删除则不发布旧回答，明确可能已产生用量。会话删除后晚到结果丢弃。资料永久删除同时清除依赖该资料的问答记录及冻结调用快照，会话容器保留；回收站内资料的历史引用标为过期。

超时、网络/服务端错误和服务中断标 unknown，禁止自动重发；错误不保存上游响应或凭证。网关目的地址冻结，待发送期间配置改变则阻止发送。网关 /v1/analyze 与 /v1/answer 共用凭证、容量及有界上游读取，但请求缓存按路由分区。缓存仍为开发进程内缓存，重启不提供持久“恰好一次”计费保证。

## 数据与兼容

schema 7→8 新增 rag_sessions、rag_turns、rag_jobs。会话及问答是业务知识，进入变更日志、固定提交、备份与可读导出；任务快照是设备操作记录，不进入知识日志/固定提交，恢复包清空 rag_jobs。历史 pending/running 问答没有本机任务时显示 unknown，不恢复为可执行付费任务。问答引用只持久保存原文 ID/版本/位置元数据，完整请求原文在操作快照中。

支持旧 schema 1～7 恢复升级，升级前按既有机制备份并校验旧触发器；schema 8 库及新恢复包不能交给旧客户端打开。可读导出新增 rag/*.md 和会话元数据，保留问题、答案和引用。没有实现云端同步、充值、账户额度预留或结算。
