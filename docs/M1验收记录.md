## M1 明确边界

- 使用开发令牌，不是正式邮箱或第三方登录。
- App 直接上传到 API，设备离线上传队列和系统分享属于 M2。
- 插件会显示发现的图片引用数量，但 M1 只归档正文和来源 URL，不上传或保存图片引用。
- 链接保存为 `link_only / needs_input`，不声称已经抓取正文。
- 当前检索是基础关键词召回；向量召回、重排序和生成式问答属于 M2。
- 本地 Agent 接入使用 stdio 和连接令牌；远程 Streamable HTTP/OAuth 属于后续对外接入。
