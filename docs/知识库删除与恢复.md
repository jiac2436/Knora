# 知识库删除与恢复

入口：Mac 左下角知识库菜单 → 管理知识库 → 删除。需确认后才执行。

本功能中的知识库是当前本地数据库内的知识域，不是整个本地数据库目录。仅本地模式开放。

- 知识域及当前未删除的资料在同一事务中移入回收站，原件、版本、证据和笔记保留。
- 管理知识库和设置的回收站均提供恢复知识库入口；此前单独删除的资料不会随库恢复。
- 库内资料不能单独恢复到已删除的库，需先恢复知识库。资料仍可按既有回收站流程永久删除，永久删除的资料不能随库恢复。
- 删除当前知识库后切换至剩余库；无剩余库时清空选择，可重新创建。
- 删除会取消待处理的知识域分析、清除自动处理授权。已经发往外部网关的调用无法撤回；恢复不会自动重启收费分析。
- 删除库名仍保留，创建同名知识库会提示冲突；可以先恢复原库。

## API 与兼容

新增本地接口：DELETE /v1/domains/{id}、GET /v1/domains/trash、POST /v1/domains/{id}/restore。

数据库版本由 15 升至 16，新增 domain_trash，保存删除时间和本次删除的资料 ID。活动列表过滤已删除知识域；采集、处理和检索拒绝已删除范围。同步快照提供删除标记。

使用现有本地宿主启动流程自动备份并迁移。旧备份仍可恢复后升级；升级后的数据库不要用旧版客户端打开。无需手动执行 SQL。原有备份不被修改。
