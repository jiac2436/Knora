# Agent 接入

本轮改造已于2026-10-29更新到唯一正式App，发布状态见 `apps/macos/release.json`。

在“设置 → Agent 接入”使用 Codex、Claude Code、Workbuddy 标签切换客户端，样式与“网页读取”和模型连接方式一致。每个客户端显示一个当前连接；Codex 与 Claude 可以同时使用，互不影响。

## 选择授权范围

知识库列表可按名称查找，列表在固定高度内滚动。点击一整行即可选中或取消，右侧显示已选数量；“选择全部”选择当前已有的全部知识库，与搜索筛选无关。以后新建的知识库不会自动获得授权，需要另行选择并保存。

至少选择一个知识库后才能接入。已有连接点击“保存授权”，直接修改原授权，不创建新凭证或新插件，也不延长原有效期。改动在后续检索请求中立即生效；已经发出并完成的检索结果不会从其他客户端对话中撤回。

授权范围仍仅覆盖已允许共享给 Agent 的资料；原本只在应用中可见的文章不会因为选择全部知识库而自动共享。

## 当前连接

- Codex：创建知识库插件后，在 Codex 插件页安装“个人知识库”，回到此页完成接入。日常更改授权范围只需保存，不用重复创建插件。在 Codex 对话中通过 @ 主动选择知识库 Skill。
- Claude Code：接入会备份原配置并保留其他服务，完成后在 Claude Code 重新加载 MCP。自动参考开关对新会话生效。
- Workbuddy：继续保留手动配置方式，本轮不宣称新增自动安装或真实宿主验收。

连接检查只做本地精确检索，不调用模型，也不要求安装语义搜索扩展。基础包已包含配置解析所需的固定 TOML 组件。

高级设置可复制私有配置、撤销凭证及查看历史。历史记录不再作为多个当前插件展示。支持的三个客户端仅最新连接可以访问；旧的重复凭证失效，撤销或过期当前连接也不会恢复旧权限。插件更新时会核验并整理同一知识库的旧市场登记；旧的有效启用配置会停用，其他资料库及被修改的条目保持。历史宿主缓存／旧文件不会被批量删除，凭证失效后无法继续读取知识；需要时在宿主客户端卸载旧插件即可。

客户端运行时提供本地服务，正常退出后不能检索。不要分享含访问凭证的配置。

## 兼容性

数据库保持 schema16，无结构迁移。只对标准客户端名称 Codex、Claude Code、Workbuddy 实施单一有效连接规则；其他已有自定义名称的 API 连接保持兼容，不猜测其所属客户端。新增 `PATCH /v1/agent-connections/{id}` 接口只接受知识库 ID 列表，保留连接 ID、token 和有效期；列表可能返回 `superseded`（已替换）状态。已有第三方调用默认形状保持。

本轮同时发布前次已验收的 OCR 逐项依赖下载改造。用户资料、模型密钥及其他应用的真实配置不随本次发布自动修改。

## 2026-10-29 补充修复

真实市场已从4条整理到1条，并修复当前插件的旧App运行路径。持续修复逻辑已于2026-10-29发布到正式App。单纯路径变化将显示“接入路径需要更新”，通过“创建/更新插件”复用已验证的私有凭证，不要求重新创建授权；真正文件改动继续拒绝覆盖。Codex从宿主缓存加载本地插件，修改源后按[官方机制](https://developers.openai.com/plugins/build/plugins)重新加载宿主。
