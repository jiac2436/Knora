# Agent 接入

在“设置 → Agent 接入”切换 Codex、Claude Code 或 Workbuddy。每个客户端使用一个当前只读连接，Codex 与 Claude Code 可以同时使用。Knora 运行时提供本机服务，退出后不能继续检索。

## 授权知识库

展开授权列表，可按名称查找并勾选知识库；“选择全部”选择当前已有知识库，不受搜索筛选影响。以后新建的知识库需要另行选择并保存。

至少选择一个知识库后才能接入。修改已有连接时点击“保存授权”，更新原连接的范围，不创建重复凭证，也不延长有效期。授权只覆盖库内已允许共享给 Agent 的资料，不会把原本私有的文章自动变成可分享资料。

## 连接客户端

- **Codex**：创建知识库插件，在 Codex 插件页安装“个人知识库”，再回到 Knora 完成接入。对话中通过 @ 选择该知识库 Skill。日常调整授权只需保存，不用重复创建插件。
- **Claude Code**：接入过程保留其他服务配置；完成后在 Claude Code 重新加载 MCP。自动参考开关对新会话生效。
- **Workbuddy**：创建连接，再把当前连接的配置复制到 Workbuddy 中完成手动接入。

“检查连接”只验证本地检索与配置，不调用模型，也不要求安装语义搜索扩展。修改本地授权无法撤回其他客户端已取得的资料。

## 更新与断开

应用路径变化时，在原连接执行“创建/更新插件”，并在宿主客户端重新加载。更新会核验文件归属，不覆盖被用户修改或属于其他知识库的配置。

支持的客户端只保留最新连接有效。断开、撤销或过期不会恢复旧权限；需要时可在宿主中卸载旧插件。复制出的配置包含独立访问凭证，请勿分享或提交仓库。

底层 `PATCH /v1/agent-connections/{id}` 只更新知识库 ID 列表，保留连接 ID、token 与有效期；被替换的连接可标为 `superseded`。数据库保持 schema16。
