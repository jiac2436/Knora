# L1 本地基础实施记录

日期：2026-09-30。状态：后端基础已实现，Mac 启动集成和完整阶段验收尚未完成。

## 已实现

- 新增 `PKA_ENVIRONMENT=local`。SQLite、原件、备份、暂存和任务目录位于用户数据目录；缓存、模型缓存及日志目录独立。拒绝相对路径、应用安装包内部路径，以及指向其他位置的数据库或原件配置。
- 默认数据目录为 `~/Library/Application Support/local.pka.knowledge-inbox`；缓存和日志分别位于同标识的 `~/Library/Caches`、`~/Library/Logs`。可通过 `PKA_DATA_DIR`、`PKA_CACHE_DIR`、`PKA_LOG_DIR` 显式覆盖。
- 本地 schema 版本 1：包含既有业务表，以及知识库、设备安装身份和迁移记录。SQLite 迁移在显式事务内执行；旧库迁移前使用 Backup API 生成一致性备份，覆盖已提交 WAL 数据。失败回滚，拒绝未知或不连续版本，检查表、字段及关联完整性。
- API、Worker、stdio MCP 在本地模式下持有共享数据锁；初始化/迁移/旧库导入持有独占锁。锁文件位于数据目录的父目录，名称为 `.<数据目录名>.service.lock`，以便阻止服务在导入发布期间创建目标目录。仅约束使用该协议的进程；外部工具仍需由用户停止。
- 首次初始化生成稳定的本地用户、知识库和设备 UUID；不要求账号登录。已有用户的库必须显式选择 `owner_id`，不自动猜测用户。已绑定用户不能通过初始化切换。
- 启动凭证经标准输入传入，只存 SHA-256；输出不含凭证。允许续期当前凭证或轮换并撤销前一凭证。本地 API 只接受安装身份绑定的当前会话；Agent 的 HTTP 和 stdio 访问须属于绑定用户并满足原授权规则。
- 本地模式不注册开发会话或邮箱账号路由，新采集资料标记为 `local_saved`。开发/测试模式继续使用现有启动和账号流程。
- 旧开发库通过只读数据库快照和原件副本导入新目录，校验文件大小与 SHA-256、拒绝链接及特殊文件，检查成功后发布。保留资料、revision、证据及关联 ID；撤销副本中的旧会话和 Agent 连接，重新建立本地身份。选定用户的保存状态变为 `local_saved`，保留原更新时间。原数据库与原件不改写。

## 兼容契约

1. 既有 `SourceRevision.id`、证据 ID、资料 ID 和本机整数 `version` 均保留。整数仅作本端展示编号；同步版本以 UUID 标识，跨端接收编号分配在 S0 实现。
2. 新本地模式使用 `knowledge.db` 和 `assets`；不会自动打开或搬迁源码目录的开发数据库。业务服务启动只检查版本和身份；不会在运行期间自动升级本地库。
3. 版本 1 基线复用当前模型及六项既有兼容列补充。后续模型结构变化必须新增版本化迁移和兼容测试，不能只改 `create_all` 或当前模型来代替升级。
4. 导入是整个旧数据库的副本，不筛掉其他用户记录；只有显式选定的用户能作为本地当前身份。其他记录留在副本中，不开放身份切换。已有本地设备身份的库拒绝走旧库导入，后续使用 L3 恢复流程。
5. 内部迁移备份是私有完整数据库，可能含历史会话摘要和账号凭据摘要；它不是对外导出包。导出时排除凭据在 L3 实现。
6. 导入前必须停止旧 API、Worker、MCP 及其他写入原件的进程；`--source-stopped` 是操作方声明，程序不能证明旧程序已停止。数据库快照与原件复制的整体一致性依赖这一前提。

## 调用方式

使用独立 Python 运行包或开发环境 Python，设置 `PYTHONPATH` 为 API 模块所在目录，并显式设置 `PKA_ENVIRONMENT=local`。

```text
python -m app.local_runtime prepare --credential-stdin
python -m app.local_runtime import-legacy --credential-stdin \
  --source-database /绝对路径/旧数据库.db \
  --source-assets /绝对路径/旧原件目录 \
  --owner-id <旧用户UUID> --source-stopped
```

凭证由启动方生成至少 256 位随机值，经管道/标准输入传入并关闭输入。禁止在命令参数、环境文件或日志里传递。导入目标必须不存在；初始化已有库须携带 `--owner-id`。初始化结果输出本地用户、设备、知识库 ID 和 schema 版本，迁移时附带备份路径。

本轮入口用于后端集成；正式客户端的 Keychain 保管、凭证注入、服务启动和续期将在 L2 接入。凭证有效期 30 天，服务管理器须在启动时准备/续期后使用。
