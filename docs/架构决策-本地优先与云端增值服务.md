# 架构决策：本地优先与云端增值服务

日期：2026-09-30。状态：用户已确认的架构方向，作为后续设计与开发依据。本文记录目标架构，不表示相关功能已经实现或通过验收。

关联：[PRD v0.1](../prd/PRD-v0.1.md)、[MVP 技术方案](./技术方案-MVP-v0.1.md)、[本地服务启动指南](./本地服务启动指南.md)。原方案中的云端统一知识库假设，由本文的本地优先决策替代。

## 1. 本地与云端职责

- Mac 应用集成运行环境、业务 API、Worker 和 SQLite，由应用管理服务启动、就绪检查、恢复与退出。用户安装后能够独立运行。
- 本地持久保存原件、资料版本、证据、个人备注、实践结果、AI 产物与检索索引。
- 免费基础能力包括本地采集、编辑、阅读、检索、MCP、导出和恢复；基础使用不依赖云端登录及会员状态。
- 云端负责账户、设备身份、会员权益、AI 额度账本、AI 任务，以及付费多端同步、保存和远端 MCP。
- 使用云端 AI 时，用户授权的任务内容会离开设备；本地存储不能被表述为数据从不上传。

## 2. 会员与数据生命周期

| 场景 | 数据行为 |
| --- | --- |
| 免费基础使用 | 本地保存和编辑，支持导出与恢复 |
| 开通会员 | 上传用户选择同步的知识库，保留既有资料、版本和证据 ID |
| 会员有效期间 | 手动上传本地变更、下载云端变更；提供云端增值服务 |
| 会员到期 | 云端已有数据继续保留，停止新增和编辑；允许下载、导出和主动删除；本地继续使用和编辑 |
| 再次开通会员 | 本地积累的修改经过版本检查后同步，冲突保留供用户处理 |

云端保存不设置因会员到期而自动清理的期限。用户主动删除仍然生效。账户容量上限需要配置化；未来免费提供 1 TB 存储仅作为待评估方向，当前不形成承诺。公开的长期保留承诺、容量和成本需另行评估。

会员权益与 AI 额度分别管理。账户与权益基础、会员订阅支付、AI 额度充值与结算分别交付；会员同步及远端 MCP 可先于 AI 消费能力发布。购买额度、会员赠送额度和实际消耗分别记账；是否允许免费用户单独购买 AI 额度、价格及有效期，留待产品方案确定。

## 3. 手动同步与并发处理

- 多端允许离线编辑，设备间同步由用户手动触发。定时 AI 分析不自动上传设备上尚未同步的修改。
- 同步开始时固定本次待提交变更；同步期间的新修改留待下一次同步。界面可以提醒暂缓修改，正确性由版本检查保证。
- 云端统一校验和排序提交。编辑提交携带基础版本；版本过旧时不能覆盖新内容，需要保留本地修改并提供冲突处理。
- 资料、正文版本、证据和 AI 产物具有跨设备稳定的唯一 ID。递增版本号不能单独作为多端版本身份。
- 本地保存持久变更记录，每个操作有唯一操作 ID。只有云端确认接收后才标记上传完成；重复提交与失败重试不得重复应用。
- 同步包含知识域、项目和资料关联；自己的提交回传只确认对应修改，不把其后的本地编辑误判为冲突。
- 删除保留同步所需的删除标记，避免旧设备重连或迟到任务使资料重新出现。
- 索引按端建立或重建，记录模型与分块版本；不直接同步正在运行的 SQLite 数据库文件。
- 区分本地保存、变更同步完成和原件上传完成；同步失败提供可恢复状态。

## 4. 云端 AI 分析

支持定时和手动分析，两者使用已明确的资料范围和固定输入版本。

- 定时分析只处理云端最近一次同步可见的数据，显示其来源同步状态；任务需配置额度上限。
- 手动分析可以使用已有云端资料，也可以在用户手动同步后触发。普通同步与付费分析具有独立任务和状态，付费分析须有明确授权。
- AI 产物独立保存，关联输入版本、证据、模型与生成时间，不覆盖用户备注和实践记录。
- 分析期间资料更新，产物标记为基于旧版；资料删除后，迟到结果不得恢复该资料。
- 云端保存任务状态和可领取结果；客户端断线不等同于任务取消。结果通过手动同步回到本地，保存后建立本地索引。
- 本设备退出不自动停止账户级云端定时分析；停用需单独请求并以服务端确认为准，离线状态不承诺立即停止消费。
- 平台模型供应商凭证由云端管理，客户端持有用户登录凭证。
- 任务使用稳定 ID，额度在云端预留和结算。重复提交、领取与重试不得重复扣费；失败和取消的结算规则在计费设计中明确。

## 5. MCP、权限与云端隐私

- 提供本地知识库与云端知识库两种明确连接，首版由用户选择。
- 两端沿用相同工具契约和稳定资料、证据 ID，并说明结果来源和同步状态。
- 本地服务停止或设备休眠时，本地连接返回明确不可用状态；云端连接可在会员有效期间独立运行。
- 两端均执行连接授权、资料可见性和删除检查。普通只读检索与消耗 AI 额度的分析能力分开。
- 自动从本地切换云端属于后续能力，须有用户预先授权，并保持同一知识库与访问范围。
- 云端远端检索、MCP 和自动分析需要读取获授权内容，采用传输与存储加密及严格权限隔离；不承诺服务器无法解密。
- 授权说明需告知：外部 Agent 获取本地 MCP 返回内容后，可能将其发送给该 Agent 使用的模型服务。

## 6. 可靠性与升级

- 导出与恢复是免费基础能力；云端同步与用于误删恢复的历史保留分别设计。
- 处理任务具备资源上限、并发限制、暂停及失败恢复；性能不足可友好提示，内存耗尽和磁盘不足需明确处理。
- 数据库采用版本化迁移、迁移前备份及失败恢复；同步协议需处理客户端版本兼容。
- 云端上线须完成数据库、资产、删除记录及已有计费模块的一致恢复演练，明确恢复点和恢复时间目标；历史回退后重新建立同步 epoch，不能复活已删除数据或重复计费。
- 更新应用保留用户数据，数据位于用户数据目录，安装包内保存运行代码和必要资源。

Mac 独立版本是阶段性交付。原 PRD 的浏览器入口、iOS/Android 分享、音频及其他 P0 保留，通过实施路线映射安排；完成 Mac 阶段不代表完整 P0 验收。

## 7. 后续需要细化的设计

工程细化已记录于[实施设计 v0.2](./实施设计-本地服务同步与AI-v0.2.md)，推进顺序与验收见[实施路线 v0.2](./实施路线-本地优先-v0.2.md)。两份文档描述拟实现方案，不代表相关功能已完成。

后续实施方案应明确同步协议与冲突界面、回收站与备份期限、删除标记清理及旧设备重新接入规则、会员到期后的服务权益、AI 价格与结算规则、模型供应商和数据保留配置。具体 SDK、云供应商及存储容量不在本次决策中冻结。

优先验收离线编辑后冲突保留、同步中断后恢复、重复操作幂等、会员到期后数据访问、AI 旧版与删除处理、重复领取不重复扣费，以及升级后的资料与证据引用连续性。
