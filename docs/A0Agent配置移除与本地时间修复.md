# Agent 配置移除与本地时间修复

## 修改

- 移除受管 MCP 配置不再读取钥匙串凭证。安装器按连接 UUID、运行环境入口和本库 endpoint 路径核对归属；Codex 还要求客户端受管标记。不调用 Agent 或模型，不需要失效凭证鉴权。
- 移除结果、失败原因及处理中状态显示在对应连接旁；已确认移除的按钮禁用，历史撤销记录保留。重复移除不存在的配置明确返回“此连接配置已经不存在”。
- 当前库以外、运行入口不匹配、用户改过结构或未受管的配置拒绝自动移除，避免误删其他连接。
- 到期时间从 API 原始时间解析为瞬间，再按系统本地时区显示年月日、时分秒及时区。SQLite 无时区时间按 UTC 解释；已有 Z/UTC 偏移的时间保留其真实含义。解析失败显示“时间不可用”。

## 兼容性

无数据库迁移，API 的 expires_at 格式不变。安装器增加本机内部 remove_owned 动作；安装、检查及手动复制仍遵循既有凭证流程。断开先关闭对应自动参考规则，再移除配置及撤销访问；部分步骤失败时保留明确提示。
