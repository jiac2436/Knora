# 短问题召回与 Agent 连接修复

## 问题与修改

真实案例是原文存在“我的名字叫杰克，我是一名程序员。”，但查询“职业”返回空。随包 BGE 模型对该词的相似度为约 0.3576，未达到常规 0.5 阈值。

- 保留正常检索阈值；仅当所有召回通道都为空且问题不超过 20 字时，从原文向量返回最多 3 个候选。阈值为 `max(0.35, 常规阈值 - 0.15)`，沿用所有授权、当前版本和标签筛选。返回 `retrieval_confidence=candidate`、相似度及 `requires_evidence_confirmation=true`。候选不是答案，Agent 必须读取原文确认；不触发付费模型。
- 正文关键词与总结关键词均由 `query` 提供。`task_context` 保留为兼容参数，不再作为扩大召回的词项，避免泛化上下文把无关资料推入结果。
- MCP 描述明确个人姓名/职业问题的检索用途、鉴权错误和没有资料的区别、候选校验要求。输入 schema 明确非空 query、limit 1–20。
- 增加只读 `list_knowledge(offset, limit)`，每页最多 20 条，只返回当前授权资料标题、ID、覆盖情况及最多 3 个原文证据 ID。包含连接 ID、获授权领域 ID、next_offset；不返回凭证或完整原文。目录查看无需构造空查询。
- `get_summary` 在 available=false 时返回 unavailable_reason 及 read_original_evidence 建议。可区分 not_analyzed、analysis_pending/running/failed/unknown/cancelled、no_current_valid_summary。后者涵盖过期、无效、分段或完成却没有有效产物的情况，不推测具体原因，不泄露模型错误或快照。
- 一键连接前刷新列表，相同名称、领域集合且有效的授权复用最新连接，不延长有效期；本机凭证缺失时提示处理。高级手动创建仍允许明确的新授权。
- 连接列表显示实际 MCP 服务名；过期/撤销连接可使用“移除失效配置”。只移除匹配当前连接的配置，备份和并发保护仍生效。

## 兼容性

无数据库迁移，不重写原文、人工标签或 AI 产物。HTTP/MCP 返回字段为增量；增加第六个只读工具。搜索中的 task_context 不再扩大关键词召回，调用方应把检索词写入 query。客户端和 Agent 需要重启/重新加载 MCP 才能发现新描述和工具。

## 限制

这是一组针对已复现问题的质量回归，不代表所有短问题都能得到正确候选。低置信候选必须由原文确认，相关性不足应回答没有依据。MCP 描述引导 Agent 使用工具，无法强制外部 Agent 每轮调用。历史多套有效连接可能有不同授权，本次不自动批量删除；可按服务名逐项断开或移除失效配置。缺失本机凭证或用户改过配置时，保护机制会要求手动处理。
