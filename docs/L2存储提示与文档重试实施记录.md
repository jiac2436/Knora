# L2 存储提示与文档重试实施记录

日期：2026-10-01。用户要求继续完成后续工作，并授权子 agent 并行开发；本轮补齐此前提出的本地存储提示和文档解析手动重试。

## 实现

### 本地空间不足

本地 API 识别原件写入 `ENOSPC` 和 SQLite 的容量耗尽错误，按现有 `ApiError` 结构返回 HTTP 503、`code=local_storage_full`、`retryable=true` 和请求 ID。提示为“本机存储空间不足，请释放空间后手动重试。”响应不包含路径、SQL 或参数。

只在本地模式转换。权限拒绝、数据库锁、非 SQLite 异常以及非本地模式保持原来的异常处理，不误报空间不足。客户端已有网络层读取结构化 `message`，因此可直接展示该提示；不自动重新发送采集队列。

### 普通文档重试

新增 `POST /v1/sources/{source_id}/document-parse`，仅允许资料所有者对有原件的普通文档重新排队失败任务。PDF 仍使用既有 OCR 入口；非文档、原件缺失、已删资料、越权和不符合状态的请求被拒绝。

重试通过条件 UPDATE 将已有 `failed` 任务改为 `pending`，复用任务 ID、保留尝试次数，清除上次错误及结束时间；不创建重复任务，不修改原件、当前版本、历史版本和用户补充。并发重复请求只有一个成功，另一个返回 409。

Mac 阅读器在普通文档解析失败时显示“重试解析”。提交后刷新当前资料，并提示稍后刷新查看结果。新增加载代次和连接检查，防止旧请求在切换资料/连接后重新选择旧文档或覆盖新请求的状态。

## 并行边界

主线程修改生产代码和已有存储故障测试、统一运行完整回归并打包。子 agent 分别只编辑新增 `test_document_retry.py`、新增 `DocumentRetryTest.swift`；第三个 agent 只读审查。没有同时编辑同一文件、共享测试数据库或由不同 agent 覆盖客户端包。

审查发现并修复了新重试函数的慢响应竞态。测试编译曾发现跨文件访问私有字段，已改用服务地址和唯一 Bearer 凭证检查连接，随后当前 Sources 全量编译通过。
