# 知识域及主题问答范围

## 客户端调用

`LocalRAGView(model: model, domainID: nil, topicID: nil, scopeTitle: nil)` 保留全库问答入口。知识域入口传入 `domainID`；主题入口同时传入 `domainID` 和 `topicID`。`scopeTitle` 仅用于标题及发送确认提示，不参与检索筛选。

范围属于连接身份的一部分。切换本地库、连接、知识域或主题后，旧异步响应不得回填新页面。重复刷新保留已有问答内容；切换会话时优先使用当前范围内的已加载记录，首次读取期间不提前显示“没有记录”。提交失败后的相同范围、会话、问题及标签继续使用原请求标识，未知结果不会自动重试。

## API

- `POST /v1/rag/turns` 原字段继续兼容；新增可选 UUID `topic_id`。知识域请求使用原有 `domain_ids`。有主题时必须指定且仅指定一个知识域。
- `GET /v1/rag/sessions` 和 `GET /v1/rag/turns` 支持可选 `domain_id`、`topic_id`，按准确范围筛选会话及问题；不传范围时显示全库问答记录。
- 问题响应新增可空 `scope`：`{"domain_ids": ["domain-uuid"], "topic_id": "topic-uuid-or-null"}`。无范围的历史记录返回 `null`，属于全库问答，不混入某个知识域或主题的问答。

主题必须属于当前用户、指定知识域及 `app` 范围。检索文件集合来自当前主题及所有子分类的有效成员，文件去重，再与当前可用资料、知识域、项目和标签条件取交集。倒排、原文向量、摘要、标签及知识域导航召回共同使用这个文件范围，不通过提示词代替过滤。空主题直接返回“资料不足”，不创建模型任务。

## 发布及历史校验

Worker 在发送问题前及发布答案前，检查冻结原文仍是当前版本，同时检查文件仍属于请求的知识域及主题后代集合。资料移域、移出主题或删除后，尚未发送的请求取消，已发送的回答不发布。已完成历史回答的引用也会标记范围失效。

## 兼容性

没有数据库结构变更或迁移。范围保存于既有 `RAGTurn.result_json` 的本地 `scope` 键，成功、失败、未知状态均保留。既有备份及同步继续承载这一 JSON 字段；不备份可执行付费任务的既有规则不变。旧客户端不传 `topic_id` 时，请求哈希保持原算法结果，重启升级后的同一幂等请求不会因新增空字段产生冲突。

范围只保存在本机问答记录中。问答网关仍收到原有 `request_id`、问题及原文证据，不增加主题目录、摘要、用户备注或权限凭证。

## 验证边界

`test_rag_scope.py` 使用合成 SQLite 资料验证真实关键词及向量召回范围、后代成员去重、跨域/跨主题/他人主题排除、空主题零调用、发送与发布前范围变更取消、历史引用失效、幂等及未知结果不重试。所有网关调用均使用模拟 HTTP，不读取用户资料，不调用真实模型。
