# 小红书内容专属阅读方案

本目录仅为设计样稿，不修改正式 App、插件或用户资料。index.html 可切换三套方案，使用同一段用户截图中的正文与部分评论；三张配图和图片数量均为布局示意，并非原帖内容。

共同规则：标题只出现在现有顶部工具栏；阅读区不展示【标题】【正文】【话题标签】等采集标记；作者和来源为弱化的元信息；话题采用轻量标签；评论与原帖正文分开，回复用缩进和细线表示，作者回复带标识；长用户名单行省略，完整采集范围在评论区展示。工具栏与来源链接仅为静态示意，图库、分区和评论折叠支持真实交互。

A 阅读优先（推荐）：正文 → 话题 → 图片缩略图 → 折叠评论。适合个人资料库连续阅读。图片点开大图，评论按需展开；长文时图片位于正文之后。

B 图文对照：左侧图库，右侧正文／评论切换。适合图中文字较多的攻略、教程和案例；宽窗口可同时对照，窄窗口上下排布。

C 分区切换：正文／图片／评论各自一页。最少干扰，适合针对性查看；代价是图文对照需要切换。

实现约束（下一轮选择后处理）：仅对匹配小红书域名的来源启用专用布局，其他来源保持现状。旧资料应优先做阅读展示兼容，避免为了排版覆盖或删除原始文本；无法可靠识别的旧分区保留原文。无图片时不出现图库空壳，无评论时不提供无效入口；评论条数说明区别采集记录与原站总数；图片失败复用已有失败与重试能力，不用截图示意替代真实内容。本轮样稿不声称支持正式 App 的编辑、标注或后台存储。

验证：三套方案截图已人工检查；独立浏览器验证单一标题、评论默认收起与展开、图库键盘切换、B 图文和评论切换、C 图片与评论切换、窄窗口无横向溢出；B 文字区域 scrollWidth 等于 clientWidth。正式 App 未更改。
