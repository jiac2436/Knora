# 知识域概览：摘要优先与预算分批

## 目标与范围

知识域概览负责知识范围、主要脉络和阅读入口；具体事实仍通过 RAG／MCP 检索真实原文核对。单篇分析、原文、人工标签、主题归属沿用既有机制。

新默认计划为 `summary-budget-v3`；2026-10-17 引用兼容修复后的加工版本为 `summary-navigation-v2`，网关提示词为 `domain-summary-navigation-v1.1`。没有新表、新依赖或数据库迁移；工作区已有 schema v16（知识域回收站），不能按旧文档误认为当前源码仍是 v15。

## 默认流程

1. 复用有效单篇分析，补齐缺失及过期资料。
2. 收集所有有效文档的标题、概览、核心要点与必要条件，使用确定性的文档顺序。
3. 完整输入可容纳时，只创建一个最终概览请求；不强制生成独立主题／中间节点。
4. 超过输入预算时，优先保持主题相邻／同组，主题过大再按文档 ID 稳定哈希分割。每篇只分配一次，未分类资料同样纳入。预览不再因为文档属于多个主题而重复预留调用；待补分析时按文档数和三路合并上界预留，不再直接按256步顶格预留。
5. 一层可汇总就结束；多批不能合并时，使用最多三个子节点的宽合并，并再次验证实际输入大小，不默认两两合并。
6. 本地更新概览索引。主题分类仍可正常使用，知识域更新不承诺同时生成每个主题的 AI 概览；单独更新某主题也使用同一预算策略。

## 长度与质量边界

- 使用 UTF-8 字节数保守上界估计 token，无新增 tokenizer 依赖；每次输入预算 48,000（含 8,192 提示词／信封预留），另为输出及安全余量预留空间。部署模型须具备至少 64k 上下文；这不是读取供应商模型规格后的自动窗口配置。
- 该估计比实际计费 token 保守。v2 本地网关信封最多 2 MiB，原文窗口单条最多 1,000 字符，仍保留总字符、条目及单篇长度限制。原文不进入供应商输入；供应商输入仍受上述 48,000 预算限制。旧 v1、单篇分析及问答的网关请求仍最多 512 KiB，过大输入明确阻断，不静默省略。
- 中间结果文字合计最多 2,200 字符，写作目标 1,200～1,800；最终域概览硬上限 500、主题 800，写作目标约 350。中间产物不承担用户短阅读摘要的职责。
- v2 中间和最终响应均允许最多 8,192 输出 token，以容纳全部合法引用 ID；字数仍按上一项单独限制。增加输出上限不代表必须生成或计费这么多 token，网关也不会为压缩另发请求。
- 每条输出建议 1～3 个、硬上限 10 个导航引用，与共享结果结构一致。所有引用仍须存在、唯一且绑定当前文档版本；引用标识只用于来源导航，不能证明模型已经阅读或验证原文。三个子节点各七条输出、每条十个引用、文字按四字节 Unicode 验证了父节点预算；实际输入始终再次校验，超限不发送。
- 本地冻结快照保留真实原文窗口，供权限校验、变更失效、原文定位及 RAG 回查；云端模型仅接收摘要和引用标识，不接收这些原文窗口。
- 摘要正文中不重复序列化引用 UUID，供应商输入不再重复携带摘要节点 ID、来源 ID 和引用对照表。来源绑定和完整依赖仍留在本地快照中，没有为了减小输入而省略文档正文概览。
- 不截断生成句子，不自动重试或新增隐含压缩调用。超长、无效引用、未知结果仍停止并保留检查点。新提示词降低了输出负担，但不保证真实模型永远遵守长度。

## 复用与兼容

复用键包含当前子集依赖指纹、请求内容和加工规则。未变化的批次可复用；全部子节点可复用时也检查父节点复用。变更只使对应批次和祖先重算，批次超限导致拓扑调整时可能扩大重算范围。

已发布 v1 原文合成产物仍保留并可读；新 v2 请求沿用结果 JSON、原文索引与备份格式，通过请求 `contract_version=2`、`purpose=overview/batch` 区分语义。旧网关不支持新请求，会拒绝而非偷偷回退。API／Worker／网关必须一起加载新源码；完整客户端需要重新组装后台运行包。

## 进度

`build_view` 和全量任务读取返回真实的完成步数、总步数与当前步骤标题。客户端将第二阶段进度按节点完成比例更新；单次模型调用期间没有伪造细粒度百分比。

## 验收

模拟模型验证：27 篇直接调用、百篇超限拆批、无重复／遗漏、宽合并、子树和根复用、输入变更失效、原文回查、供应商请求无原文、鉴权／幂等缓存、失败／未知停止、旧产物及备份恢复。

对当前用户库只读预估：27 篇纳入 27 篇，无排除，3 个模型步骤，累计输入预留 113,211；原计划为 121 步。预估不调用模型，也不改变真实任务或正式产物。

2026-10-17 精简重复标识后的只读重算：同一知识域 27 篇纳入 27 篇、零排除，完整输入可容纳，改为 1 次汇总，输入预留 31,936。旧失败任务保留，必须通过新预览创建新任务，不会自动恢复或重发旧请求。模拟复现确认旧版隐含的三个引用限制会拒收四个有效引用，但此次没有取得真实失败响应的详细诊断，不能断言真实任务只存在这一种错误。
