# A0：客户端 Agent 连接管理

日期：2026-10-03。延续只读 MCP 与 Skill 接入，补齐本地客户端的连接配置体验。

## 使用流程

本地模式进入“设置 → Agent 接入”，填写连接名称，勾选至少一个授权领域，设置 1～365 天有效期（默认 30 天）。创建连接后可复制 Codex MCP 配置、刷新连接状态、确认撤销连接。列表只属于当前用户，展示有效、过期、已撤销及授权领域，不返回凭证。

每个连接使用独立只读 Agent 令牌，不使用客户端 owner 或 AI 网关凭证。原有领域授权、app_only、删除、过期与撤销过滤继续生效。令牌创建时存入当前知识库独立的钥匙串服务；保存失败时只在当前窗口临时保留，界面提示先复制。服务端不能恢复旧令牌；本机令牌丢失时撤销旧连接并重新创建。

复制结果使用随包 Python 的隔离 stdio 入口及绝对路径，以 TOML env 显式提供 PKA_AGENT_TOKEN 和 PKA_API_FILE，不依赖桌面应用继承终端环境变量。配置包含独立令牌，只应保存到本机私有配置，不可分享或提交仓库。本批不自动改写全局 Codex 配置、不自动安装知识库 Skill。后续已补齐 Claude Code、Workbuddy JSON 配置，验收范围见 [多客户端配置记录](./A0多Agent配置实施记录.md)。

## 重启与端点发现

本地 API 和 Worker 就绪后，宿主原子发布当前知识库 data/agent-api.json，权限为 0600，仅含 api_url、library_id、instance_id，无任何凭证。正常停止时只清理仍属于当前实例的端点，拒绝符号链接、非常规文件、外部用户或宽权限文件。进程被强制杀死可能残留旧端点，下次启动会替换。

MCP 每次读取时重新解析端点，支持同一知识库重启后的端口变化。客户端关闭时仍可启动 stdio 并发现工具，但读取会报告服务不可用，不回退为直接访问数据库。显式 PKA_API_URL 开发配置保持兼容并优先于端点文件。转接仍限制回环 HTTP，禁用代理和重定向。

配置绑定应用运行环境及知识库路径。移动应用、恢复知识库或改用其他知识库后需重新配置；原库退出后对应配置不可访问。撤销或过期立即拒绝读取。
