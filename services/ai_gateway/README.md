# Knora 模型执行器

本目录的模型执行代码已包含在基础 App 中。直接模型模式由内置 Worker 调用共享执行器，不新增网关进程或监听端口；用户在“设置 → 模型与 AI”配置服务即可。

| 文件 | 职责 |
| --- | --- |
| `execution.py` | 统一模型任务执行与结果校验 |
| `settings.py` | 不可变模型配置与参数检查 |
| `provider.py` | 上游服务请求 |
| `prompts.py` | 分析、问答及概览提示词 |
| `vision.py` | 图片输入验证及处理 |
| `errors.py` | 有界、安全的错误信息 |
| `main.py` | 可选的外部 HTTP 网关适配器 |

共享契约位于 `services/api/app`。修改契约或执行逻辑时，同步验证 Worker 与接口消费者；不能只更新原生 App 而继续携带旧后台。

开发及启动外部网关见 [BUILD](BUILD.md)，免费模拟回归见[开发与验证](../../docs/开发与验证.md)。外部入口不是日常桌面使用的前提。

真实模型调用可能计费。身份校验、输入大小、图片与引用校验、结果缓存及失败/未知状态均需保留；健康检查不发送文章，也不能证明模型余额、权限或回答质量。密钥、原文和上游原始错误不应进入公开日志或代码仓库。
