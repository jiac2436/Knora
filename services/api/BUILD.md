# 共享内核开发与构建

完整客户端按 [macOS BUILD](../../apps/macos/BUILD.md) 从固定输入组装。源码导入成功不能替代随包验证，不能把旧后台目录直接套进新 Swift App。

开发依赖、隔离测试和单项回归命令见[开发与验证](../../docs/开发与验证.md)。外置 API/Worker 命令见[服务启动指南](../../docs/本地服务启动指南.md)，普通使用者不需要独立后台。

## 修改后的验证范围

1. 修改业务接口、权限或持久化时，执行相关 API 回归；涉及 Worker 时同时验证任务状态、取消与失败路径。
2. 修改模型契约时，连同 Worker 与 `services/ai_gateway` 共享执行器更新，先使用模拟模型和合成资料验证。
3. 修改随包接口或平台能力时，重建运行包与 App，验证真实回环服务、MCP、重启和备份恢复；客户端仅编译通过不足以证明兼容。
4. 修改扩展输入时，重新生成固定锁、下载清单和许可索引，验证实际安装及推理。

数据库当前为 schema16。格式变更应保留必要备份与迁移步骤；不要编辑历史验收记录使其显示通过。测试和构建产物留在忽略目录，不提交真实数据库、资料、凭证或模型文件。
